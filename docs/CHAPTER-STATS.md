## 南北线对比（`python tools/chapter_stats.py --write` 生成，别手改这一节）

同一章的南线、北线并排。口径：

- **格数**＝quest 里 `squares` 的总数，含互斥分支（所以比玩家一轮实际走的格子多）。
- **事/选/战/宝/休/募/？**＝七种格子各有几个：事＝剧情 `event`、选＝抉择 `choose`、战＝战斗 `battle`、宝＝宝箱 `treasure`、休＝回复 `recover`、募＝招贤 `recruit`、？＝奇遇 `mystery`（每种的玩法见 `sanguo-dev` skill 的「Square types」）。
- **战斗 普/精/首**＝普通 / 精英（`elite`）/ 首领（`boss`）三档战斗格数，它们合起来就是「战」那一项。
- **分叉**＝`choose` 格 + 有 `lose_goto` 的战斗格。
- **CG**＝格子挂了 `cg` 的张数 / 其中 `pics/art.json` 已交付的张数。第一章是一个 quest 的两条线，按 x 坐标分开（南 0–22，北 23 起）。
