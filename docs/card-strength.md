# 卡牌强度设计

## 品阶（按重复张数，跨周目记着）

| 品阶 | 张数 | 倍率 | 比上一阶 |
|---|---|---|---|
| 铜 | 1 | ×1.00 | — |
| 银 | 4 | ×1.30 | +30% |
| 金 | 16 | ×1.75 | +35% |
| 神 | 64 | ×2.40 | +37% |

- 张数是累计的（`dupes` / `lord_copies`，**新周目也不清零**：已经拿到的卡再抽到，回来还是原来的级别，继续往上升；主公同理）。
- 4 倍递增：铜→银 3 张、银→金 12 张、金→神 48 张，神是长期目标（要几个周目的积累，或者多次点化）。
- **点化**（战功或事件）一次给这张卡加 `gacha.upgrade_copies`（现 3）张：铜（1 张）一次到银（4 张），银（4）→ 7 仍是银，要点两次才到金（13→16 差 3 张再点一次）。想让点化更值就调大 `upgrade_copies`。
- 配置全在 `cards.json` 的 `gacha.tiers` / `upgrade_copies` / `rarity_bands`；神的卡框暂用 SSR 框，等专属框图。

## 一张卡的数值

- **卡面就是数值**：每张卡直接写 `hp` / `at`（铜的数值），各在 40..100；稀有度由 hp + at 落在哪一档决定
  （`gacha.rarity_bands`：N 80~99、精兵 / C 100~124、R 125~149、SR 150~174、SSR 175~200）。打手 `at` > `hp`，策士 / 后勤 `hp` ≥ `at`。
- 品阶倍率乘在卡面上，所以 **SR 铜 ≈ C 银、SSR 铜 ≈ C 金**——重复卡和高稀有度大致等价，不会只有 SSR 值得抽。
- 队长攻击 / 体力 = 5 × 队长单卡 + 同兵种其他出战卡；同种兵卡第 i 张按 `floor + (1 − floor) · decay^i` 计
  （`gacha.soldier_decay` 0.8、`soldier_decay_floor` 0.5），主公队的亲卫另按 `battle.lord_member_mult` 折算。
- 敌人的数值也来自它的卡面（`battle.enemy_from_card`），再乘档位系数和章节曲线（`battle.scaling`，校准方法见 sanguo-test skill）；
  每个难度等级 +`battle.ending_step`。
- 技能威力按 AP 档位（`skill_budget`，见 `docs/skills.md`），和品阶无关；品阶只放大攻击和体力。
- 测试守着：`test_every_card_sits_in_its_rarity_band_and_in_40_to_100`。

## 常用的牌更容易升级

`gacha.fielded_chance`（现 0.3）：招贤的每个位置、宝箱里的每张牌，有这个概率直接是你**现在上场**的牌——正在带队的武将（没满阶）、或出战兵种（主公队 + 各队长所带兵种）里没被留下的兵卡。用得多的牌多拿到重复张，更快升阶。宝箱被限定了卡池的格子（`only`）不受影响。
