# 卡牌强度设计

## 品阶（按重复张数，跨周目记着）

| 品阶 | 张数 | 倍率 | 比上一阶 |
|---|---|---|---|
| 铜 | 1 | ×1.00 | — |
| 银 | 4 | ×1.30 | +30% |
| 金 | 16 | ×1.75 | +35% |
| 神 | 64 | ×2.40 | +37% |

- 张数是累计的（`dupes` / `lord_copies`，**新周目也不清零**：已经拿到的卡再抽到，回来还是原来的级别，继续往上升；主公同理）。
- 4 倍递增：铜→银 3 张、银→金 12 张、金→神 48 张，神是长期目标（要几个周目的积累，或者多次点化）。
- **点化**（战功或事件）一次给这张卡加 `gacha.upgrade_copies`（现 3）张：铜（1 张）一次到银（4 张），银（4）→ 7 仍是银，要点两次才到金（13→16 差 3 张再点一次）。想让点化更值就调大 `upgrade_copies`。
- 配置全在 `cards.json` 的 `gacha.tiers` / `upgrade_copies` / `rarity_mult`；神的卡框暂用 SSR 框，等专属框图。

## 一张卡的数值

单卡 = (兵种基础 + 卡自己的 bonus) × 稀有度倍率 × 品阶倍率（兵卡没有品阶，只看稀有度 N 0.8；同种兵卡多一张按 ×0.6 衰减累加，所以下表只列武将和主公）。
稀有度倍率：N 0.8 · R 1.0 · SR 1.15 · SSR 1.35（保证同兵种里 SR / SSR 永远压过兵卡）。
队长攻击 / 体力 = 5 × 队长单卡 + 部队其他成员（同兵种所有出战卡牌；主公队另有 `lord_member_mult` 0.6 折算）。

| 卡（单卡 攻 / 体） | 铜 ×1.00 | 银 ×1.30 | 金 ×1.75 | 神 ×2.40 |
|---|---|---|---|---|
| 赵云 SSR 枪 | 135 / 729 | 176 / 948 | 236 / 1276 | 324 / 1750 |
| 张飞 SR 枪 | 109 / 610 | 142 / 792 | 191 / 1067 | 262 / 1463 |
| 文聘 R 枪 | 83 / 505 | 108 / 656 | 145 / 884 | 199 / 1212 |
| 主公 | 80 / 400 | 104 / 520 | 140 / 700 | 192 / 960 |

## 几个对照（设计意图）

- **一张神 R ≈ 一张金 SSR**（R 神 2.40 vs SSR 金 1.35 × 1.75 = 2.36）：收集广度和品阶深度大致等价，不会只有 SSR 值得抽。
- **SR 银 略强于 SSR 铜**（1.15 × 1.30 = 1.50 vs 1.35）：SR 多抽 3 张就追平一张新 SSR，重复卡不白抽。
- **主公的品阶和武将同一套**：主公神 ≈ 主公铜的 2.4 倍，主公队长的 5 倍系数再乘上去，所以主角队的强度主要靠品阶、亲卫和主公卡。
- 敌人侧：每章 +10%（`chapter_step`），每个难度等级 +15%（`ending_step`），难度等级只靠结局解锁；一个全铜的队伍打到第五章约要面对 +40%，银卡（+30%）刚好抵消，金卡以上是真正的余量。
- 技能威力按 AP 档位（`skill_budget`），和品阶无关；品阶只放大攻击和体力。
