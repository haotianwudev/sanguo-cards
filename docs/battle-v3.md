# 战斗体系 v3：读招 · 打断 · 换人登场 · 首领机制 · 军令

> 状态：**已实装**（2026-11-01）。承接 `docs/skills.md`（技能体系 v2）。原规划稿里冗长的部分（7 种换阵强袭、四段冲阵动画、护盾、
> 半血转阶段、首领全面扩到 8–12 招、弹性防御、一大堆演出）放弃了；留下的都在下面，配置在 `godot/data/battle.json`、
> `skills.json`、`enemies.json`，代码在 `battle.gd` / `auto_player.gd` / `battle_screen.gd` / `tactics_overlay.gd`。

## 为什么

v2 之后，「每 AP 打最高伤害」的贪心机器人就能拿到目标胜率——玩家怎么打差别不大。v3 让每回合都有要想的事：
敌人这回合要干什么？要不要留 AP 打断？换谁上来？兵刃还是谋略？——再用「军令」让自动战斗也会这些。

## 1. 意图（敌人每回合亮牌）

- 回合开始 `Battle._plan_intents()` 就把敌人本回合的全部行动抽好（`enemy.intents`），敌方面板显示「意图：重击 · 蓄力·回血」。
- 敌人回合按这个队列执行，不再临时掷骰。被打断 / 被眩晕时重排（眩晕 = 「意图：眩晕」，什么都不做）。
- 文字由 `intent_label()` 按招式字段自动生成：攻击 / 重击（power ≥ 1.5、穿甲、比例伤）/ 施毒 / 烈火 / 惑乱 / 夺气 / 回血 / 狂暴 / 架势 / 唤援；
  蓄力招显示「蓄力·杀招 / 回血 / 叫援 / 狂暴」（看它蓄的那一招），蓄好落地那一下显示「绝招【X】」。

## 2. 蓄力三类 + 打断

- 蓄力的写法不变：招式 `"charge": "<招名>"` 宣告，下回合第一动放那一招（`weight: 0`）。被蓄的招带 `heal` 就是**蓄力回血**，带 `summon` 是**蓄力叫援**，带 `rage` 是**蓄力狂暴**。
- **打断**：技能效果 `{"type": "interrupt"}`。敌人蓄力时命中 → 蓄力作废，我方 AP +1，敌人破防 +25%（2 回合）（`battle.json charge_break`），演出「破招！」。不在蓄力时什么也不做。
- **普通眩晕不打断蓄力**，只让敌人跳过一回合（蓄力顺延）——打断是专门的资源，不是 40 个眩晕技能随手就有。眩晕和打断都会打散敌人的架势。
- 带打断的技能（10 个，两线主公都有）：主公 扔刀 `rengdao`（南）/ 回马枪 `huimaqiang`（北）、张飞 当阳怒吼、黄忠 百步穿杨（还对蓄力中的敌人必暴）、
  甘宁 锦帆夜袭、张辽 辽来辽来、关羽 威震华夏、荀攸 十二奇策、程昱 十面埋伏、华佗 麻沸散。敌人蓄力时这些按钮金色描边。

## 3. 敌人智商（`Battle._move_weight`）

所有敌人：满血（>80%）不回血；架势 / 前卫已在场不再开；我方火、毒还剩 ≥2 回合不再补；我方 AP ≤1 少夺气；同一回合不连抽同一个纯状态招。
精英 / 首领 / 必败战另外读牌：
- 自己体力 <35% 回血 ×3；我方 AP ≥6 夺气 ×2；我方战意 ≥2 层或 ≥2 人 BOOST 时惑乱 ×2；我方体力 <45% 重击 ×2。
- 招式 `prefer`（字符串或列表，满足 ×3）：`player_high_ap` `player_buffed` `player_low_hp` `party_burning` `party_poisoned` `first_round` `self_low_hp`。
- **读打断**：我方还有没用掉的打断技能 → 蓄力招 ×0.5（会忍）；打断都用光 → ×1.8（抓破绽）。
- 连段 `"chain": "<招名>"`：同一回合下一动必接那一招。

## 4. 首领机制：架势、前卫

- **架势** `"stance": {"name", "power", "turns"}`：期间我方每放一个**兵刃**技能，敌人迎面反击一下（`power × 攻击`，吃我方减伤）；谋略、毒火、反击不触发；眩晕或打断立刻打散。
- **前卫** `"summon": {"name", "hp_pct", "strike"}`：首领身前多一条前卫血条（首领最大体力 × hp_pct）。普通兵刃先打前卫；**谋略、穿甲越过前卫直接打首领**；毒火只烧首领；前卫每个敌方回合跟着砍一刀；首领倒下即胜。
- 已配的首领：吕布（除测试用 `lvbu` / `lvbu_hulao`）= 画戟架势 + 蓄力狂暴；赵云 = 七进七出（架势）；夏侯惇 = 刚烈（架势）；
  曹操 = 蓄力叫援「虎卫军」；诸葛亮 = 蓄力叫援「卧龙门生」；孟获 = 蓄力叫援「藤甲兵」+ 蓄力回血；董卓 = 蓄力回血「酒池肉林」；袁术 = 蓄力叫援「仲氏亲兵」；许褚 / 典韦 = 蓄力狂暴。
- **叫援铺开（用户 2026-11-06）**：有名有姓的精英 / 首领大多会叫援（约四成精英首领，79 个敌人）：`<兵种>·蓄力` 宣告，下回合唤出「<人名><亲兵 / 亲骑 / 亲卫 / 护卫 / 喽啰>」（按他卡牌的兵种），前卫血量 精英 12% / 首领 15%，`strike` 0.5；首领 `prefer: self_low_hp`，精英 `player_buffed`。可以和架势、护盾等其他机制并存（精英也不限一个机制）。兵卡 / 野兽敌人、单挑比武（比武招亲、吕玲绮）不叫援。
- **前卫每回合普攻（用户 2026-11-07）**：前卫在场时，每个敌人回合都打一次「<前卫>·普攻」（首领攻击 × `strike`，首领被眩晕时也打）。意图栏会一直写出这一下，招式牌也显示它。
- **兵刃 / 谋略（用户 2026-11-07）**：玩家看到的「物理 / 法术」全部改叫「兵刃 / 谋略」（代码里仍是 attack / magic）。**弓兵、贼的每一下伤害一半兵刃一半谋略**（`battle.split_troops`，技能和突袭都算；兵刃那份吃兵刃抗性、先打前卫 / 护盾，谋略那份吃谋略抗性、越过）。**战意（献策 / 献计）的攻击加成打在谋略伤害上翻倍**（`battle.buff_magic_mult` 2）。

### 4b. 新机制：点名、护盾、变阵、封技（用户 2026-11-03）

**每个精英都有一个机制**（蓄力 / 架势 / 前卫 / 护盾 / 封技，在原有招式之外加），**首领一个或多个**，按人物特点配（`data/enemies.json` 各敌人的 moves）。

- **点名** `"mark": "<那一招>"`：像蓄力一样占一个行动，点我方攻击最高的队长；下回合第一招打他——**他还在阵上，就被打倒（卡变灰带裂纹、角标「倒」，本场不能再行动，可以换下），我军还直接损失体力上限的 1/4**（`battle.mark_pct`，防御、减伤都不管用）；**换下他就扑空**（按 `Battle.swap_key` 认人：主公换成另一张主公卡也算换下）。点名时「点」字大印砸在卡上、卡上红光和火星一直到出招，出招时卡上一记红色十字斩。只给大首领：吕布、董卓、袁术、华雄、文丑、关羽（比武）、马超、孙策、陶府摔杯为号。被点的卡发红光、带「点」角标，意图写「斩将【X】→名字」。军令条件「敌人点名」，中军动作「换下被点名 / 被打倒的」（出厂军令第一条）。点名的应对只有换人（第 1 回合起能换，1 AP；替补里没人可换就只能硬吃）。
- **护盾** `"shield": {"hp_pct"}`：敌人身上一层护盾（最大体力 × hp_pct，统一 0.2，用户 2026-11-07），**打不破盾的兵刃（含穿甲、弓兵、大招）整下被挡、盾掉血；一下打破盾的那一击伤害全中，等于没有盾**；**谋略直接越过**（用户：鼓励一记大招直接破盾）；毒火不碰盾。角标「盾」，命中飘「盾 -N」，打碎「护盾碎了！」。
- **变阵** `"formation": {"vs": "attack"|"magic", "cut", "turns"}`：某一种伤害 -cut（默认 60%）几回合，敌人会在两种阵之间换；**眩晕打乱阵型**。只用在后期的阵法战：诸葛亮八阵（生门 / 景门）、八阵关羽（石阵）、曹仁「八门金锁」（休门挡兵刃 / 惊门挡谋略；原来的八门金锁蓄力大招改成了阵，曹仁卡牌技能不变）。角标「阵」。
- **封技** `"seal": "ultimate"|"magic"|"attack"`（`seal_turns` 默认 1）：封我方大招 / 谋略（含火毒）/ 兵刃技能一回合，**解除状态可解**。给谋士、搅局的人：郭图、程昱、周瑜反间计、王朗、刘备以仁止戈、黄巾符咒等。我方角标「封」。

## 5. 换人

- **主公也能换人**：换成他的另一张主公卡（`SaveData.swap_roster` 带上本线其他主公卡，`Battle.swap_key` = `lordform:<form>`；换下的那张还能再换回来）；武将的位子不能换上主公卡。
- 花 **1 AP**，第 1 回合起就能换，每回合 1 次；**只能换本回合还没出手的队长**；换上来的人**当回合就能放技能**。
- **登场必定触发一次他兵种的小技**——就是每回合小概率触发的那个，算法不变：骑兵突袭、枪兵本回合必定还击、刀兵举盾列阵、弓兵射穿甲缝、贼一声唿哨（BOOST）、策士出谋划策、后勤照料伤兵（`Battle._troop_trick` / `_raid` / `_entry_trick`）。

## 6. 技能配合（`skills.json` 效果字段）

- `crit_if`: `stunned` / `charging` / `broken` / …：条件成立必暴。贼兵「偷袭」对眩晕敌人必暴；黄忠「百步穿杨」对蓄力敌人必暴。
- `vs`: `{条件: 倍率}`：条件成立时乘。马超、关羽、徐晃、周泰的招牌技对破防敌人 ×1.4。旧的 `burning_mult` 读作 `vs.burning`。
- 条件词：`broken burning poisoned stunned charging guarded stance`。

## 7. 军令（自动战斗）

战斗右上「军令」（`TacticsOverlay`，三个分页），存在 `Game.options.tactics`（所有存档、两条线、每个周目通用；读的时候走 `AutoPlayer.with_defaults`）。
**三层**（用户定）：**整体**、**兵种**、**武将**。每条军令都是「当 [条件1] 且 [条件2] → 动作」，每项最多 4 条，从上往下第一条成立且做得到的就执行。条件 18 个（`battle.json tactics.conditions`，含换人用的「场上没人会谋略」「场上没人能解状态」「打断技能用光」「有队长大招用尽」）。

- **整体**：三档预设——**拆招**（默认：打断留到敌人蓄力、防绝招、留气）/ **猛攻**（只输出）/ **省技**（限 1 大招留到首领战）；加**中军军令** `party_rows`，动作 `party_acts`：全军防御、结束回合（留 AP）、**换人规则**（换上某兵种 = 替补里最强的那个顶掉能换的最弱队长；换下大招用尽的 = 换成替补里最强的）。默认带两条：「敌人架势 且 场上没人会谋略 → 换上策士」「我军有异常 且 场上没人能解状态 → 换上后勤」。
- **兵种**：`troop_rows[兵种]`，动作是技能类别 `troop_acts`（普通技 / 招牌技 / 大招 / 打断技 / 治疗解除 / 增益防守，`AutoPlayer.skill_kind`），按每位队长自己的技能对上（普通技取最便宜的，其他取最贵的）。
- **武将**：`rows[卡 id]`，动作是这张卡的具体技能，可勾**留气**（这条只差 AP 时，别人只放 0 AP / 回 AP 的技能）。同一位队长先看武将军令，再看兵种军令。

**出厂军令**（用户要求，`battle.json tactics.defaults`，整体页「恢复默认」一键还原）：每条都带条件，平常回合仍交给预设估值，只在这些场面替玩家做对的事。
- 中军：敌人架势且没人会谋略 → 换上策士；我军有异常 / 体力 <40% 且没人能解状态 → 换上后勤。
- 兵种：主公队 敌人蓄力 → 打断技；贼 敌人眩晕且 AP 满 → 普通技（AP 不满时不抢大招的 AP）；后勤 有异常 / 体力 <40% → 治疗解除；策士 有前卫 / 架势 → 招牌技，首领有前卫 → 大招；刀兵、枪兵 敌人蓄力且打断用光 → 增益防守；骑兵、弓兵 首领战敌人破防 → 大招。
- 主公：敌人蓄力 → 扔刀（南）/ 回马枪（北）打断，留气（AP 不够时别人先别花）。
- 武将（23 张主要角色卡）：马超 / 徐晃 / 关羽 / 周泰 破防时放对破防加成的招；赵云 / 孙策 首领战破防放大招；周瑜 / 诸葛亮 有前卫或架势放火；张辽 / 甄宓 打断用光时用眩晕拖蓄力；华佗 / 张宁 / 小乔 有异常解、低血治；郭嘉 首领战开局放十胜十败；孙权 首领战低血放坐断东南。
- 玩家存过的那一层以玩家为准；兵种、武将两层按每个兵种 / 每张卡分别覆盖，没碰过的照旧用出厂值（清空 = 故意不要）。军令永远不放「现在什么也不做」的技能（满血治疗之类）。
- 平衡（`SIM_BOT=tactics SIM_DEFAULTS=1`，可写 `party_rows` / `troop_rows` / `rows` 只开一层，`SIM_TROOP=<兵种>` 只开一个兵种）：南北各 12 局，开出厂军令 24/24 通关（不开 23/24）。试过又删掉的：贼「敌人眩晕 → 普通技」（玉碎首领 80% → 39%：拿 1 AP 偷袭换掉了大招）、「首领战有人大招用尽 → 换下」（换人花 AP 掉节奏，玉碎首领 → 42%）。

`AutoPlayer.plan()` 每步顺序：破招（预设 `interrupt`）→ 中军军令 → 每位队长的武将军令、兵种军令 → 留气 → 默认估值（会看架势、前卫、蓄力；拆招 / 省技把打断技能留着）→ 有蓄力杀招要落地就防御（`defend_charge`）/ AP 满防御 / 结束回合。

## 7b. 回合数

所有战斗的回合上限统一 +2（`battle.json turn_bonus`），精英战再 +2、首领战再 +5（`tier_extra_turns`，取代旧的 `boss_extra_turns`）——都是用户要求，加在关卡自己的 `turn_limit` 上（`Battle.turns_for`，地图战前情报同一个数）。
