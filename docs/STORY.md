# 剧情大纲：周目与路线

数据在 `godot/data/story.json`，写作规则在 `.claude/skills/sanguo-dev/SKILL.md`「Story voice」。
这份是给人看的总图：哪一周目走哪条线、靠什么旗标分岔、每章讲了什么。改了剧情请顺手更新这里。

## 周目总览

每次打出结局都会回到标题、开新周目：卡牌收藏保留，结局旗标（`结局一 · 玉碎`、`结局二 · 同归`）永久保留，
其他剧情旗标只在本周目有效。

| 周目 | 条件 | 路线 | 终点 |
|---|---|---|---|
| 一周目 | — | 第一章 → 第二章 → 第三章·传国玉玺（南阳） | **结局一 · 玉碎** |
| 二周目 | 有「结局一」，且第二章留下董白（`董白：留下`） | 第三章开头董白认出并救下蔡文姬 → 第三章·驻守洛阳 → 第三章·长安 → 第四章·围府 | **结局二 · 同归** |
| 三周目起 | 有「结局一」「结局二」，且留下董白 | 同上，第四章貂蝉来报信 → 护驾东归 → 讨伐袁术 | 南阳（未完待续） |

二周目以后，第二章若交出董白，仍会走回一周目的南阳线和结局一。

## 第三章（二周目起的长安线，简述）

- **驻守洛阳**：蔡文姬的身世，劫郭汜的粮，**朱儁**来投（孙坚的老上司，托主角带话给皇甫嵩），**灯下习字**（蔡文姬手把手教主角写名字，写坏的那张她留着；她弹一段，主角写一遍），联军散，
  李儒求和，主角提议联系王允，董白许婚，**邙山跑马**（董白：「以后家里我说了算」「那以后，我就是你家里人」），去长安。
- **长安**：接风宴（董卓羞辱**皇甫嵩**，西凉三将比武），**朝见**（小皇帝悄悄问主角从哪来、能不能带他走），
  住蔡邕府；主角因为从电视剧里知道连环计，主动托蔡邕引荐王允——王允先装忠于董卓（「天日可表！送客！」），主角点破貂蝉、当场献计，王允才关门换了副脸；出连环计（许婚 → **月下**：献貂蝉前一夜，她只为主角跳了一支没有乐声的舞，「……逗你的，谁看都一样」 → 献貂蝉、凤仪亭），**除夕**（董白拉主角上相府屋顶许三个愿，第三个「跟你有关」——她什么都不知道），吕布被关，**雪夜**（大婚前夜蔡文姬替主角缝好喜服领口、亲手给他穿上：「她不知道，我知道」；然后为他弹了一曲只弹过一次、没有名字的曲子），大婚是董卓的陷阱，格杀勿论，
  貂蝉放出吕布来救（「诛此贼！」），皇甫嵩带禁军杀到，吕布杀董卓，董白崩溃。

## 第四章 · 挟天子（quest `dongui`）

一张地图。前半段两个周目相同，从「报信 / 围府」那一格开始分岔：两条路占同样的格子位置，
靠 `requires` / `unless: 结局二 · 同归` 只显示其中一条。

### 共同开头

1. **夷族**：王允要夷董卓三族。主角挡在董白身前，皇甫嵩站到他身边，小皇帝开口「朕不想再看见死人了」，
   郿坞保住了。董白从此不和主角说话。
2. **请孙坚**：牛辅出逃，被亲兵胡赤儿为几箱金子杀死（董白的姑父）；西凉兵群龙无首，求赦。主角请王允赦免西凉兵、请孙坚入长安，王允都拒绝了（「请一头老虎进城替老夫看门？」）。
3. **封侯**：吕布封温侯，孙坚进封吴侯，皇甫嵩任征西将军。王允不想封主角，小皇帝坚持：**富春亭侯**
   （「那里江里有鱼，一年到头都吃不完」）。周瑜、孙策来长安接封。
4. **招揽**：
   - 天牢里放出**荀攸**。他一出门就预言西凉兵三月内必反、王允容不下主角；家叔荀彧比他小六岁。
   - 尚书台结识**钟繇**。小皇帝早让他画了一张回洛阳的路线图；主角讨了他的字，「够在老家换一套房」。

### 二周目：围府 → 结局二 · 同归

5. **围府**：没人报信。钟繇扔进墙来的纸条「快走」来得太晚。天亮前，吕布的并州狼骑和高顺的陷阵营围了蔡府；王允下诏把主角就地格杀，
   蔡邕因「为董贼叹息」下狱。
6. **后门·高顺**（精英）→ **突围**：与从驿馆杀出来的孙策、周瑜会合，一起往宣平门杀
   （荀攸在驿馆被围，跟孙策、周瑜一起会合，最后随他们冲出城门）→ **长街·并州狼骑**（精英）→ **破祠**（回复，蔡文姬接琴弦：「你教我石头剪刀布吧」）。
7. **董家**：董白带着飞熊军老兵来了（董璜闭门不见，老兵一个不少全来了：「小姐小时候给我们送过饭」；西凉大将在城外，胡轸、徐荣已降王允）（「我不是来救你的。你还欠我一句话」）。
8. **宣平门·吕布**：打不赢的最后一战，输赢都进结局。貂蝉坐在吕布马后，别过脸去。
9. **同归**：
   - 城门撞开一道缝，主角断后，逼孙策、周瑜冲出去报信（「账本上你欠我的，得活着还！」）。
   - 王允在城楼上，蔡文姬当面痛骂他「无耻」。王允让她走、答应放她爹，她不走：「你在哪儿，我就在哪儿。」
   - 蔡文姬和董白和好（「没身材那句，不收回」）。董白也和主角和好：「你娶我，是不是真心的？」「是。」「……骗子。」
   - 「见到吕布，要跑。全天下都知道的道理，我偏偏没跑。」「跑了，谁陪你们俩。」
   - 三人手牵手，一起往前走了一步。长安下着那一年的最后一场雪。
   - 貂蝉惋惜：「那天夜里，妾身该去敲公子的窗的。」
   - 结局卡：「殊途同归……也许下一周目，会有人来敲你的窗。」

### 三周目起：报信 → 东归 → 讨伐袁术

5. **报信**：貂蝉夜里敲窗，出卖义父王允（「义父把妾身送给董卓的时候，可没问过妾身愿不愿意」），
   告诉主角：王允要除掉他，吕布是那把刀。
6. **乱兵起**：李傕、郭汜兵临长安，王允处处牵制吕布（「只许守，不许追」）。周瑜借叔父**周忠**的门路，
   劝主角带陛下走；逃跑路线用钟繇的图，荀攸判断追兵走渭水南岸、我们走北岸。
7. **北掖门**：小皇帝抱着包袱（「朕说过，朕不占地方」），董白带飞熊军旧部来护驾（她说「送天子回洛阳」，老兵一个不少全来了），貂蝉跟着一起走，
   皇甫嵩守宣平门断后。
8. **哨卡·清明门** → 二选一：**司徒府追兵** / **山道·樊稠**（都是精英）→ 华阴守将段煨（董卓旧部）送粮 → **徐晃**倒戈护驾（荀攸看出杨奉的兵军心不稳，让陛下露面）
   → **函谷关·李傕**（首领）。
9. **洛阳**：孙坚单膝跪迎天子。
10. **长安陷落**：王允死在宣平门上，吕布突围，直接投了河内的张杨（并州时的老相识；「蝉儿的账，我记着」）。朱儁、皇甫嵩在洛阳宗庙前重逢。李傕、郭汜占了长安，
    一个管兵一个管钱，**没有内讧**。
11. **玉玺**：孙坚不还玉玺，还奏请大将军、录尚书事。挟天子以令诸侯的成了孙坚
    （「课本上说的明明是曹操啊」）。
    荀攸：「挟天子的人，天下都看着他，也都盯着他。」钟繇留在宫里，替小皇帝抄孙坚的诏书。
    吴夫人夜里劝孙坚「那东西会害死人的」；主角隐约「梦见」过玉碎，也开始怀疑「征讨刘表时战死」那行字还算不算数。
12. **排挤**：孙坚以大将军的身份在洛阳挟天子以令诸侯。小皇帝开口，主角被封**破虏将军**（孙坚把自己以前的名号给了他）。
    吴景（「离陛下远点」）、孙贲都排挤主角。孙坚看他不爽，又知道他有本事；自己要守着天子走不开，
    只给两千兵，派他去讨袁术。荀攸随行（「这盘棋在洛阳下不开」）；钟繇送来小皇帝亲笔写的「早点回来」。
13. **南阳**：出征 → **营寨·桥蕤** → **黄忠**来投（南阳军汉，袁术的兵抢了他家的米，儿子黄叙病重；
    一箭射断「袁」字旗）→ **山道·雷薄** → **星夜**（攻城前一夜，蔡文姬要主角兑现「石头剪刀布」——她说是在梦里答应的；她在星空下弹一首还没有名字的曲子；主角许诺「你被带到很远的地方，我去接你回来」）→ **宛城城下·陈兰**（精英）→ **冯夫人**夜里来劝降；孙坚在南阳驻过兵，城里的旧部认他临行给的虎符，约好开东门，里应外合
    → **宛城·纪灵**（首领，替袁术断后）→ **袁术东逃**（出征时周瑜卖了舒县的家产充军粮，「这一笔，不记」；拿下宛城那夜董白和主角和好，石头剪刀布第一次赢）：纪灵护着袁术和冯夫人一起逃走；按史实，袁术逃到九江，
    占了寿春，自领扬州牧。主角拿下南阳（未完待续）。

## 史实校对（第三、四章）

已按史实改过：袁术 190—191 年在宛城（不是寿春）；孙坚驻鲁阳；冯夫人是袁术的宠姬；蔡邕考主角念《熹平石经》（汉代还没有对联）；
蔡琰字昭姬（「文姬」是晋代避讳改的，主角叫惯了）；孙坚由乌程侯进封吴侯；李傕追天子时长安还没破；牛辅之死；吕布出长安后直接投张杨（史实是先投袁术、再投张杨，后来才去袁绍那里，这里简化了）。
有意保留的改写：时间线压缩、孙策周瑜的年龄、董白和蔡文姬写成成年人、董白活下来、吴夫人碎玺、孙坚挟天子、皇甫嵩带禁军参与诛董、李傕郭汜不内讧。
