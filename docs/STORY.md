# 《三国卡牌》全剧情宏观大纲与设定详案
### —— 双线史诗：从双击穿越到双龙归一的大一统总纲

> **这份文档只是故事方向，不是实现清单。** 真正的游戏一章一章做：每做一章，按当时的设计在 `godot/data/story.json` 里写细，做出来的内容为准，再回头把这里的梗概同步过来。还没做的章节，这里的情节、人物、年龄都可以改。

## 一、 核心世界观与底层设定（Meta-Premise）

### 1. 穿越契机：天道代码的“双击 Bug”
* **主角原型**：现代 30 岁资深打工人（社畜），前世干了十年采购。**三国演义当年没读完，读过的也记不太清了**（「三国演义我不熟啊」「早知道会穿越，当年就该把那本书读完」）；三让徐州、三英战吕布这类人人都知道的大梗，以及课本、游戏和电视剧里的名人他还认得，细节一概模糊，大多数人物他都「没听过」；精通现代企业财务核算、组织架构与供应链管理，嘴碎幽默，是个逗比，深谙保命之道，但骨子里极重情义。
* **时空分裂**：加班到凌晨三点，主角点开一款叫《重开三国》的游戏。在出生点选择界面，他的鼠标意外**连续双击**了两个互斥选项——**【南方 · 江东富春（吴夫人）】** 与 **【北方 · 冀州无极（甄家，张夫人）】**。（游戏里玩家每一周目只选其中一个出生点；另一个分身也在同时活着，这一点直到后面才揭开。）
* **数据冗余与实体分裂**：
  * 天道底层系统判定出现严重竞态条件（Race Condition），为防止崩溃，将同一个玩家灵魂（拥有完全相同的 UID、记忆、思维习惯与现代口癖）克隆并投射到了两个不同的肉身容器中，分别投放于公元 190 年（初平元年正月）的江南富春江畔与北方太行山口的雪地。
  * **两具身体**：面容如出一辙，但并不完全一样——南线身体十八岁，顶着前世那头扎手的现代寸头（汉代短发等于受过髡刑，吴夫人爱摸、孙策孙坚爱笑），后来穿孙坚当年的银甲（虎纹护肩、白毛滚边黑披风），用孙坚的旧刀（古锭刀，扔刀就是它）；北线身体约莫二十来岁，**束发**，穿甄宓亡父留下的鱼鳞甲、外罩雪白貂皮披风，用一杆白蜡杆长枪（赵云教的枪法，枪杆上系着甄宓编的红色平安结）。身体随故事一起长大：南线初平元年（190，第一章）十八岁，到第五章初平四年（193）二十一岁，此后逐年增长；北线从二十来岁起同样逐年增长。立绘和台词按章节里的年纪写。
  * **隐性伏笔**：两边的主角均不知道对方的存在，但随着天下兼并、政令互通，现代管理学词汇（如“降维打击”、“闭环”、“赋能”、“复式记账法”）开始在南北两端同时涌现。

### 2. 双线叙事结构
* **南线（孙家 / 荆襄 / 江东 / 西南）**：
  * 风格：波澜壮阔的水上史诗、江东风流、多女主柔情与铁血托孤。
  * 核心将领/谋士：孙策、周瑜、黄忠、甘宁、贾诩、荀攸、蒯越。
  * 核心女主角：吴夫人（长辈）、董白、蔡文姬、貂蝉。大乔嫁孙策、小乔嫁周瑜——是兄弟的妻子，不是主角的红颜。
* **北线（甄家 / 常山 / 徐州 / 河北 / 辽东）**：
  * 风格：中原逐鹿、重装铁骑、商道治国、名士交锋与边塞风云。
  * 核心将领/谋士：赵云、太史慈、马腾、马超、郭嘉。
  * 核心女主角：张夫人（甄家主母，待主角如子）、张宁（医仙，张角之女，信众仍叫她圣女）、吕玲绮（二十岁左右，吕布之女；只在北线出场）、甄宓（第一章十三四岁，主角待她如亲妹妹，干净的兄妹情；她随故事一章章长大，终章已是成年女子，嫁给主角）。

## 二、 第一卷：潜龙在渊（第一章至第五章·南北分立）

### 第一章：风云初动（190年 春）

#### 【南线：富春江畔 · 孙氏结义】
* **【初平元年 · 正月】落水之厄**：主角被孙坚正妻**吴夫人**从富春江里捞起，醒来是一具十八岁的身体。吴夫人待他像儿子，摸他的寸头、给他换药吹伤口，对他的油嘴滑舌照单全收却浑然不觉——这份「傻乎乎的母性」就是笑点。孙坚北上讨董，把壮丁都带走了，村里只剩老弱和两个少年。
* **孙策与周瑜**：孙策见面就拿枪顶人鼻子，莽、不会水、被留在家里生闷气；周瑜聪明却小气，随身一本**账本**，谁欠他什么都记着（主角喝的那碗粥，米是他家的）。
* **富春山庄夜袭**：钱塘水寇「浪里蛟」胡玉趁壮丁不在，带着混进来的黄巾汉子夜里烧了富春山庄，把吴夫人掳进水寨。孙策主张正面强攻、周瑜主张放火调虎离山，玩家选谁的计，谁就先入队。救出吴夫人时，胡玉一眼认出主角扛的刀：「这是孙坚当年在钱塘砍我的那把刀！」压惊宴上吴夫人给主角夹了三块红烧肉。
* **端掉何仪大寨**：胡玉逃去江心大寨，和黄巾渠帅何仪合兵；妖道唐周在寨前设坛作法，放话要拿孙家祭旗。村里没壮丁，主角就自己征兵（丹阳兵、长沙刀兵），一路打上大寨。吴夫人从宝库里只挑回了她的首饰盒，又把孙坚年轻时的银甲给了主角（「后来他胖了，穿不下了」）。
* **江边三结义**：按年齿，主角大哥（比孙策大一岁、比周瑜大两岁），孙策老二，周瑜老三——「桃园？咱们这是江边！」此后孙策叫他「短毛大哥」，他叫孙策「虎子」、叫周瑜「三弟」（背后叫「周扒皮」，被听见要罚一文钱）。
* **吴夫人的针线**：出发前一夜，吴夫人在灯下给他缝一件带毛边的厚冬衣（「北边冷」），孙策蹲在窗外攥着自己缝得歪歪扭扭的破棉袄：「……我也要。」主角第一次在这个乱世里体会到家的温度。
**关卡（游戏里：`prologue` 南方分支）**
- 开局二选一：跟周瑜上山（挖出他的私房钱）/ 跟孙策去打野猪（战斗：野猪林）。
- 夜袭 → 定计二选一：孙策线「寨门 · 水贼喽啰」→ 首领「水寨 · 浪里蛟胡玉」；周瑜线放火调虎离山 →「回援的水贼」（伏击）→ 首领「看门水贼」。救人：吴夫人入队。
- 征兵（招募格）→「芦苇荡 · 水贼喽啰」/ 险滩 →精英「妖道唐周」/ 江边扎营休整 → 首领「何仪大寨 · 黄巾渠帅何仪」→ 水寨宝库 → 旧甲 → 江边三结义 → 北上（丹阳兵、水贼兵、南下黄巾入队）。

#### 【北线：中山雪夜 · 甄府结缘】
（已实装：`prologue` quest 的北方分支，x ≥ 23，目前以「北线 · 敬请期待」收尾。）
* **【初平元年 · 正月】雪地逢生**：主角冻僵在太行山口的雪地里，被甄家商队捡回**中山无极**的甄府，醒来是一具二十来岁、束着发的身体。甄家当家主母**张夫人**（三十多岁，精明干练，嘴上严厉，心里拿他当自家孩子）考他算账；主角拿出复式记账、平准仓、私人护卫队，一个月里甄家粮库由告急变成囤满，张夫人把半副账本甩给他。十三四岁的**甄宓**扒着门框喊他「账房哥哥」——干净的兄妹情。
* **真定县衙与街头郭嘉**：开春，袁绍在渤海起兵讨董，冀州刺史（韩馥，怂）下令「倾全州之粮支援盟军」。袁绍派来的督粮亲信**郭图**要搜刮刚遭雪灾的常山真定，银甲青年**赵云**带乡民陈情，挨了棍子也不肯对官兵动手。街角酒旗下，醉醺醺的**郭嘉**冷眼讥讽。主角出面，以甄家名义借出三千石麦子，不收利息；郭图不敢惹甄家，骂骂咧咧走了。
* **黑山贼突袭与破寨救宓**：
  * 张夫人押粮去常山施粥，带上了甄宓。车队在太行峡谷被黑山贼魁**李大目**、黄巾渠帅**张白骑**伏击，自称承了张角衣钵的妖道**玄机子**掳走甄宓。
  * 郭嘉在雪地上画图定计：主角去上风口放火，赵云从水洞潜入，郭嘉在前门敲锣、冒充公孙瓒的大军。赵云在血祭坛前枪挑玄机子，抱着甄宓出来；主角抡起护卫的长枪、姿势难看地架住李大目的巨斧，赵云回马一枪刺穿他的咽喉；张白骑跳下山崖逃走。
  * 赵云、郭嘉当场入队（「往后我跟你混了」）。黑山寨的存粮连同甄家的三千石，在常山开仓放粮，青壮、黄巾降卒、猎户跪地投效，成了主角第一支嫡系部曲：常山铁骑、太行义勇。
* **赵云教枪**：放粮之后的半个月，赵云天不亮就把主角拖到雪地里——「打李大目那天，你是把枪当顶门杠用的」。扎马步一个时辰，第三天学会拦、拿、扎，第七天一枪扎穿了晾在院子里的张夫人的狐裘，被追了半个院子；赵云难得笑出声：「……准头是有了。」从此主角用枪，师父是赵子龙（主角内心：一对一带教，放游戏里得充钱）。
* **南下会盟**：围炉夜话，主角断言袁绍、韩馥、公孙瓒都不是明主（公孙瓒「早晚被困死自焚」）；郭嘉带来消息：十八路诸侯正在关外讨董。主角决定「自己拉一支队伍，南下中原，会一会天下的英雄」。张夫人自称「娘」，拿出三千匹战马、三千副铁甲、十万斛军粮，又把甄宓亡父的鱼鳞甲给他披上（甄宓的父亲当年护商队，死在黑山贼手里），系上雪白貂皮披风；甄宓在他的枪杆上系了一个红色平安结。
**关卡（游戏里：`prologue` 北方分支，x ≥ 23）**
- 全是剧情格，直到太行：「上风口 · 黑山游骑」→「祭坛 · 妖道玄机子」→ 休整 → 首领「黑山寨 · 黑山凶寇李大目」。
- 入队：赵云、郭嘉（团聚）；常山铁骑、太行义勇（放粮）。结尾记「北线 · 敬请期待」，出结局卡回标题。

### 第二章：洛阳烟云（190年 二月 至 初夏）

#### 【南线：汜水虎牢 · 义释董白】
* **【初平元年 · 二月】出征**：另一位兄弟也跟上了队伍。孙坚本人不入队，嘴毒（叫主角「嘴甜的」、把他往前排塞），只借给他一员老将。
* **祖茂与华雄**：祖茂戴着孙坚的赤帻引开华雄；主角赢了，扔出孙坚的旧刀，拿回赤帻；输了，孙坚亲手斩华雄。
* **董白**：反击路上拦路的是李傕帐下的偏将——董卓的孙女董白（银白高马尾、紫色毛边甲、使双锤，「你们三个，一起上！」），精英战。缠斗半天，主角把刀扔了出去，刀背砸在她的护心镜上，把她砸晕扛回营（两兄弟一人抬一柄锤，周瑜记「搬运费」）。她绝食三天，第四顿是主角端进去的红烧肉；之后被主角教会了石头剪刀布，连输七把。
* **吕布**：吕布夜里单骑闯营来接徒弟（「白儿！为师来接你了！」——他是董白的师父），并州游骑在营里放火；之后的追击战几乎打不赢——输了是三英战吕布（张飞「三姓家奴休走」），赢了难度上升、得三只宝箱、威震诸侯。
* **董白的命运**：袁绍派人来要人。交给袁绍能换一件宝物，但她必死无疑；藏起来（「路上被吕布劫走了」），她就被塞进吴夫人的马车，吴夫人给她梳头。董卓随后派人来给孙家提亲，提的正是董白（藏着的、或者已经死了的），孙坚拒了。
* **洛阳灰烬与井中玉玺**：联军按兵饮宴、干等两个月，洛阳在初夏烧起大火；城门下击退李傕。**孙坚**在宫里一口冒五色光的井中捞起传国玉玺，眼神从此变了——回江东的船上，他夜夜抱着锦盒不睡。
**关卡（游戏里：`taodong`）**
- 北上二选一：官道「西凉游骑」/ 小路「郭汜」（路上可能撞见压寨夫人胭脂虎）。
- 阵前救祖茂 →「战华雄」（输了孙坚斩华雄，赢了救下祖茂）→ 孙坚借将 →「官道 · 西凉斥候」/「小路 · 西凉弓骑」→ 华雄营宝箱 / 军帐休整 →「飞熊军」/「李儒伏兵」（伏击）→ 精英「董白」→ 大营休整 → 俘虏的日子。
- 「截粮 · 西凉斥候」→ 吕布劫营 →「劫营 · 并州狼骑」→ 首领「追兵 · 吕布」（30000 体力，基本是剧情杀）→ 三只宝箱（赢了才有）→ 董白的命运。
- 驻军（和亲）→ 精英「大谷 · 徐荣」→「追击 · 西凉斥候」→ 密信、火光 →「洛阳 · 西凉游骑」→「焚城 · 李傕」→ 洛阳（宫女入队；留下了董白的话，董白和她的西凉女亲兵也入队）→ 井中玉玺 → 来投（招募格）。

#### 【北线：洛阳烟云 · 逐鹿中原（虎牢逃婚）】
* **时间**：初平元年（190年）二月 ～ 初夏（和南线第二章同时）
* **舞台**：黄河南岸古道 → 酸枣联军大营 → 汴水 → 虎牢关前 → 黄河北渡
* **我方核心**：主角、赵云、郭嘉、张夫人、甄宓（十三四岁）、吕玲绮（二十岁左右，本章入队）
* **登场群雄**：袁绍（盟主·爱开会不拍板）、曹操（愤青阿瞒）、曹洪、徐荣、吕布（吕玲绮的父亲）、刘关张
* **为什么带着张夫人和甄宓**：联军十几万人要吃饭，甄家是去卖粮、谈生意的——张夫人亲自押车，甄宓死活要跟（「哥哥去哪我去哪」）。

**故事线（六幕）**

1. **第一幕：黄河古道 · 夜奔的红衣姑娘**
   * 【初平元年 · 二月】车队渡过黄河往酸枣走。古道上一骑红甲姑娘（二十岁左右，红黑铠甲，提一柄小一号的方天画戟）满脸泪痕地狂奔过来，以为撞上了关东联军的斥候，戟尖直指前锋：「滚开！天下男人没一个好东西！」
   * 赵云白马迎上，五个回合震飞她的画戟；她拨马就逃，冻土打滑，连人带马摔出去好几丈。赵云的枪直取咽喉——主角终于赶到，破锣嗓子一声吼：「子龙！住手！！是个姑娘！！！」挺枪一架（赵云教的拦枪，这回用上了），火星在她喉咙前半寸炸开。
   * 她瞪着主角：「你们……是来打虎牢关的？」{lord}把枪往地上一插，双手撑膝喘气：「打什么虎牢关！我们是河北卖粮的，路过！你全责追尾，打不过还翻车！」
   * {lord}（内心）：红黑甲、小号画戟……游戏里见过一张卡，叫吕玲绮，吕布的女儿。卡面上那股冷劲儿，跟眼前这个哭花了脸的，不太一样。

2. **第二幕：营地 · 张夫人的「半个闺女」**
   * 主角把脚踝脱臼的她抱上马车，用烈酒给她洗手腕上的割伤，顺手正骨（「别动，忍着点——咔哒！」）。她这才说实话：吕布为了讨董卓欢心，要把她嫁给董卓的侄子董璜，她砸窗逃了出来。
   * 张夫人掀开车帘，一听就掉了眼泪，把满脸是泥的她搂进怀里：「天杀的当爹的！拿亲闺女换官当！……不怕，到了甄家，就是娘的半个闺女。」甄宓把一块温热的栗子糕塞进她手里：「姐姐不哭，吃甜糕！」
   * 主角递过一碗羊肉汤：「在我这儿，你不是吕奉先的女儿，你就是吕玲绮。疼了就哭，装什么天下无敌。」她捧着汤碗，哭得一塌糊涂，发誓死也不回虎牢关。记「吕玲绮：入队」。

3. **第三幕：酸枣 · 【中山甄记 · 讨董慰劳义勇】**
   * 联军缺粮，杂牌军进营只会被当炮灰。主角的主意：当赞助商。郭嘉借着酒劲，在一面红锦大旗上写下八个金字【中山甄记 · 讨董慰劳义勇】，副旗「河北首富 · 倾情赞助」。守营小校看见几十车肥羊、好酒、白面，眼睛都绿了，一路敲锣把车队迎进中军。
   * **诸侯宴**：十几路诸侯天天开会、开完就喝酒，一谈出兵就顾左右而言他。{lord}（内心）：袁绍——爱开会、从不拍板的那种老板。（和南线那位一模一样的吐槽——毕竟是同一个人。）郭嘉吃了一顿饭就出来了：「袁本初只学了周公礼贤下士的样子，不懂用人。」
   * **曹操借粮**：整个大营只有一个矮个子将军拍桌子要打——曹操。他兵少粮缺，厚着脸皮来借粮。{lord}（内心）：曹操！这个我当然知道，「宁教我负天下人」那位……眼下看着倒像个被同事气得跳脚的项目经理。选择：【借】→ 记「曹操：借粮」，曹操回赠一卷《孟德新书》；【不借】→ 记「曹操：没借」（第六章他肯不肯结盟，看这一笔）。

4. **第四幕：汴水 · 救曹操**
   * 曹操孤军西进，主角放心不下（「借出去的粮，总得看着它别打水漂」），带常山铁骑远远跟着。荥阳道上先撞上一队西凉追兵。
   * 汴水边，曹操被董卓的老将**徐荣**打得大败，中了箭，马也没了。{lord}（内心）：徐荣？没听过。……能把曹操打成这样的，不会是什么无名之辈。
   * 打退徐荣之后，主角在乱军里找到曹操：曹洪正把自己的马让给他（「天下可无洪，不可无公！」）。主角顺手又牵了一匹常山战马给曹洪：「两位都别客气，马管够。」记「汴水：救下曹操」。回酸枣休整。

5. **第五幕：虎牢关前 · 吕布劫粮**
   * 【初夏】联军磨磨蹭蹭开到虎牢关下。吕布出关搦战，连挑几员联军将领；当夜又带着骑兵出来劫营——专挑粮多的打。那面「中山甄记 · 倾情赞助」的大旗，在夜里亮得像个靶子。郭嘉：「……这旗，是我写的。」
   * 车厢里的吕玲绮浑身发抖——她认得那声咆哮。主角跳上马车，拉上厚棉帘挡在她前面：「别出声。他是来抢粮的。」吕玲绮低着头：「……我知道。他从来不是来找我的。」（吕布根本不知道女儿跑去了哪。）
   * 飞熊军先冲进营里抢粮车，并州狼骑跟着放火（两战），然后吕布亲自杀到——这一战几乎打不赢：
     * **打不赢（正常）**：赤兔马转眼就到了车前，一戟挑飞主角的枪——「三姓家奴休走！燕人张飞在此！」张飞、关羽、刘备从斜刺里杀出，**三英战吕布**。{lord}（内心）：这个我知道！电视剧里看过——红脸的关羽、黑脸的张飞、双剑的刘备……真人比电视里还吓人。吕布被三人缠住，悻悻退回关里。
     * **打赢了**：吕布被一个卖粮的打退了，脸上挂不住，扔下一句「你给我等着」退回关里。记「吕布：粮车没抢走」，难度上升，三只宝箱。
     * **跨线彩蛋**：若存档里有南线的「吕布：击败！威震诸侯」，吕布出关时脸色更难看：「又是你们关东的……前几天一个短毛刚让我丢了脸！」{lord}（内心）：短毛？这年头还有人剃寸头？
   * 帘缝里，吕玲绮看着那个曾经崇拜的父亲从马车边冲过去，连看都没往车里看一眼。一只手伸过来，把她冰凉发抖的手严严实实握住，十指相扣：「别看了。往后你不用再当谁的附属品——有我一口饭，就有你一口肉。」她反手扣紧。记「吕玲绮：车帘后牵手」。

6. **第六幕：黄河边 · 回冀州**
   * 西边的天烧红了——洛阳起火。传言一个比一个快：董卓烧了洛阳、挟着天子往长安跑；有人说孙坚在洛阳宫里的井里捞着了宝贝；袁绍听说韩馥软弱，心思早就不在董卓身上，急着回冀州抢地盘。联军一哄而散。
   * 黄河渡口挤满了各家的溃兵乱卒，抢船、抢粮。主角的车队被一伙乱兵堵在渡口（最后一战）。
   * 赵云问去哪。主角跳上车辕：「回冀州！袁绍急着回去夺韩馥的地盘，公孙瓒也盯着，河北马上要变成神仙打架的大戏台——更要紧的是，咱们甄家的家底在无极县，子龙的乡亲在真定县，回去把篱笆扎紧！」郭嘉灌了一大口酒：「回去看戏，好。」吕玲绮红着脸挥挥小画戟：「谁敢动甄家我第一个捅死他——回去你得顿顿给我烤肉吃。」张夫人摸着甄宓的头：「回无极，吃热乎汤面。」记「北线：班师冀州」，第三章接回乡路过真定。

### 第三章：乱世微光（190年 夏 至 192年）

#### 【南线：长安惊变 · 文姬与连环计】
游戏里南线第三章分成三张地图：
* **传国玉玺（一周目必经，初平元年夏—秋）**：出洛阳时，若留下了董白，她会在难民里认出**蔡文姬**，主角救下她；否则蔡文姬被山贼掳走。袁术断粮，孙坚退回鲁阳；孙策在酒馆说漏了玉玺，被桥蕤听见。孙坚把玉玺托给吴夫人，不顾主角「小心岘山」的劝告去打刘表。桥蕤盯梢、陈兰夜袭、雷薄追击，最后一道关口是袁术麾下最强的纪灵（曾和关羽战过三十回合）——击败他之后，他亲口告诉吴夫人孙坚已死在岘山。袁术亲至，打不赢 → **【结局一 · 玉碎】**。
* **驻守洛阳（周目路线 B：有「结局一 · 玉碎」且留下了董白，救下蔡文姬后提前结束第三章）**：郭汜押送百官家眷沿途劫掠，周瑜定计劫粮，郭汜被击退；孙坚坐镇洛阳，联军散去；朱儁到来入队，托主角给皇甫嵩带一句话；李儒求和，主角提议找王允，董白与主角订婚（婚礼在长安）。
* **长安（初平元年冬 → 初平二年正月）**：董卓出城迎接孙女；接风宴上他要孙女婿配得上她，让樊稠、张济、牛辅（董白的姑父）跟主角比武，主角一刀背把牛辅拍在地上，董卓大笑「不愧是能把我孙女打晕的人」。小皇帝（十岁左右的孩子）偷偷问主角从哪来、孙坚在哪、能不能带他走。主角**因为看过电视剧知道连环计**，主动找上王允献计（王允先装董卓的忠仆，事后把功劳揽走）；献貂蝉的前一夜，貂蝉在司徒府后园跳了一支只给他看的舞；董卓的接风宴上贾诩在角落里一杯杯闻酒；蔡邕与蔡文姬重逢。连环计三步走（许婚、献貂蝉、凤仪亭），全瞒着董白——除夕夜她拉主角爬上相府屋顶许了三个愿，什么都不知道。李儒识破，吕布被锁进相府地牢，貂蝉被收进后院；大婚前夜蔡文姬在雪里为他弹了一曲只弹过一次的曲子。婚礼是董卓的陷阱，连董白一起杀；关键时刻，被貂蝉私自放出来的吕布带兵杀到（「诛此贼！」），董白挡在爷爷身前，**吕布当着她的面在相府杀了董卓**——她一直以为婚事和和解都是真心的。皇甫嵩倒向王允，入队。

#### 【北线：黑山风云 · 斑马义旗（界桥之战）】
* **时间**：初平元年（190年）夏 至 初平三年（192年）春——一章跨两年，每一幕开头标【年号 · 月】
* **舞台**：常山真定（赵云老家） → 太行山麓 → 黑山大寨 → 无极县甄府 → 界桥古战场
* **我方核心**：主角、赵云、郭嘉、吕玲绮（二章入队）、张夫人、甄宓、夏侯兰（本章可入队）、张宁（本章入队）、张燕（盟友）
* **交锋各方**：张白骑的黄巾残党、黑山叛党于毒、袁绍（郭图、麹义、文丑）、公孙瓒

**故事线（七幕）**

1. **第一幕：回乡 · 真定夏侯兰**
   * 【初平元年 · 夏】渡过黄河回冀州，车队先拐到常山真定——赵云的老家。乡亲们记着那三千石麦子的恩，杀猪宰羊夹道迎接，赵云被一群大娘围着塞鸡蛋，耳根通红。
   * 当天夜里出了事：几个太行义勇出身的兵喝多了，顺手偷了老乡两只鸡，被县里管刑狱的小吏当街按住，按律要打二十军棍。那小吏铁面无私，连主角派去说情的亲兵也一并按住。
   * 赵云赶到，一愣：「……是你。」小吏眼皮都不抬：「子龙，你回来了。偷鸡的是你的兵？那就更该打。」——这是赵云从小一起长大的发小**夏侯兰**，精通汉律，认死理。
   * {lord}（内心）：夏侯兰？没听过。……不过敢当着三千铁骑的面打主帅的兵，这人要么是傻子，要么就是我缺的那个人。
   * 吕玲绮在一旁啃着鸡腿看热闹，被夏侯兰一眼扫过：「这只也是偷的？」吕玲绮：「……是买的！」主角赶紧掏钱。
   * **抉择**：【请他执掌军法】→ 主角当众把二十军棍照打，再把夏侯兰请进帐：「子龙主外攻坚，夏侯兄主内纪律！没有铁律的队伍走不远！」夏侯兰入队，记「军纪：严明」（**决定第五章徐州生死**）；【嫌他碍事，赔钱了事】→ 记「夏侯兰：打发」，他留在真定（第五章结局八的提示「在常山找一个懂法度的人」指的就是他）。

2. **第二幕：太行悬壶 · 张宁**
   * 【初平元年 · 秋】主角带人进太行收山货、探商路（甄家的生意要走山道），林间杀声震天：一群狂热的黄巾残党围住几个黑山猎户和一位背竹药箱、素白布衣的姑娘——**张宁**（张角的女儿，信众口中的圣女，十九岁左右）。
   * 领头的是第一章跳崖逃走的黄巾渠帅**张白骑**，他没死，正要把「圣女」绑回去当旗号：「有大贤良师的女儿在，黄天就还能立起来！」残党骂她：「身为大贤良师的亲闺女，不用符水，拿草根针石给泥腿子治病，背叛神明！」
   * 张宁手持金针，声音不大却很冷：「我爹的符水，连他自己都没救活——他是病死的。能救人的是青蒿、柴胡和针，不是符。」
   * {lord}（内心）：张角我知道，「苍天已死，黄天当立」。张角还有个女儿？……还是个只信医术、不信符水的。这游戏的策划倒是真懂。
   * **抉择**：【拔刀救人】→ 记「张宁：救下」；【事不关己，回无极】→ 记「张宁：没救」，跳过本章的黑山线，直接到第五幕（这一步决定第五幕的生死，见下）。
   * 救人线：赵云挑翻残党，吕玲绮横扫狂徒，张白骑带着最后几十个狂信徒退进山谷死守——**中段首领：张白骑**。打完张宁入队，把父亲留下的《太平要术》交给主角：「这东西害了太多人。你拿着，别让人再拿它当旗号。」之后强制休整。

3. **第三幕：黑山 · 张燕与太行经贸协定**（救人线）
   * 张宁领主角上太行绝顶，见黑山真正的大当家**张燕（飞燕）**。{lord}（内心）：张燕？没听过。……能让十几万山民服他，绝不是只会抢的土匪头子。
   * 张燕开口就问：「杀我寨中人的，是你？」{lord}：「劫商队、掳孩子、要拿人血祭旗的那伙，是你寨中人？」张燕沉默半晌——李大目、玄机子本就不听号令。
   * 张燕要看主角的诚意：黑山另一股叛党**于毒**不服号令，下山劫掠魏郡，正好把账一起清了——**精英：黑山叛党 · 于毒**。
   * 打完，主角拿出张夫人甩给他的半副账本，当场代甄家签下《太行经贸协定》：甄家以盐、铁、布、药换山道、矿产、木材和护送。记「黑山：结盟」；张燕给了一枚**黑山令**，又拨来一队黑山游骑。
   * 张夫人起初死活不肯（「宓儿她爹就死在黑山贼手里」），直到张燕亲手把当年劫商队那伙人的头目绑到她面前，她才咬牙签了字：「……活人要吃饭。签吧。」

4. **第四幕：斑马战旗**（救人线）
   * 整编黑山义军与常山铁骑。黑山尚黑，常山尚白，主角把战袍和大旗设计成**黑白竖条**，正中一个朱红「义」字：「西方古国有一支『斑马军团』，又叫『老妇人』，黑白分明，专打防守反击！」郭嘉笑得酒都洒了：「黑白分明，晃瞎袁绍。」甄宓给大旗缝了第一针。

5. **第五幕：袁绍夺冀州 · 郭图抄家**
   * 【初平二年 · 秋】韩馥被袁绍连哄带吓让出了冀州。袁绍入主邺城，第一件事就是筹军费；郭图记着真定那三千石麦子的旧账，带着冀州兵直奔无极甄府，说甄家「私通黑山」。
   * **救了张宁（有「黑山：结盟」）**：张燕的人早从太行秘道把张夫人、甄宓和甄家的家底转进了山里，郭图扑了个空，一路追进太行山口，被斑马旗堵个正着——「太行山口 · 冀州军」一战，郭图光着一只脚逃回邺城。
   * **没救张宁**：没有黑山的山道和人手，主角带着骑兵连夜赶回无极，甄府已被冀州兵围死——「无极 · 冀州大军」，打不赢（lose_goto）→ **【结局六 · 覆巢】**。

6. **第六幕：界桥前夜**
   * 【初平三年 · 春】袁绍和公孙瓒在界桥摆开了阵。郭嘉在地图上点了点：「两边都不是好东西。可公孙瓒要是今天死了，袁绍明天就腾出手来收拾太行。」
   * {lord}（内心）：公孙瓒……我在夜话里说过他早晚自焚。可那是以后的事，今天他还得活着替我们挡袁绍。
   * 主角引兵埋伏在侧翼高地，等一个时机。界桥前，袁绍的先锋**麹义**带着八百「先登死士」，大盾一竖，硬生生把白马义从冲垮了。{lord}（内心）：麹义？没听过。……八百人打垮几千骑兵，这放到哪儿都是狠人——**精英：界桥 · 麹义先登营**。

7. **第七幕：界桥之战 · 敌住文丑**
   * 公孙瓒溃逃，袁绍麾下猛将**文丑**拍马狂追。{lord}（内心）：文丑！这个我知道，「颜良文丑」，电视剧里被关羽……算了，那是以后的事，眼下他是真能打。
   * 黑白斑马旗从高地上冲下来。赵云白马银枪独战文丑五六十回合，主角和吕玲绮引铁骑穿插——**首领：界桥 · 文丑**。
   * 公孙瓒被救下，当场赠五百匹幽州白马：「这份情，伯珪记下了。」黑白斑马义军骑兵大成。记「北线：太行立足」，第四章接郑好、姜巧和吕布北来。

### 第四章：天子之争（191年 至 193年）

#### 【南线：奉迎天子 · 经略南阳】
* **王允掌权（初平二年二月）**：主角拦下王允要夷董卓三族，小皇帝开口保住了郿坞（董卓九十岁的老母亲还活着）；请王允赦免西凉军、接孙坚入长安，都被拒绝。论功：吕布温侯，孙坚吴侯，皇甫嵩征西将军；小皇帝硬是越过王允，封主角为**富春亭侯**。主角收下荀攸（天牢里，一眼看穿王允）和钟繇（尚书台，替皇帝画好了出逃路线）。王允随后和吕布密谋杀他。
* **死局分支 · 一周目（没有「结局二 · 同归」）**：没有人报信。吕布、高顺包围蔡邕府（蔡邕因为替董卓叹了口气被下狱），孙策、周瑜一起突围，董白带着董家仅剩的人赶来，吕布堵在宣平门 → **【结局二 · 同归】**。
* **护送献帝 · 后续周目**：貂蝉（王允的养女）深夜敲窗报信；李傕、郭汜攻长安，王允拿吕布当缰绳；周瑜（随叔父周忠在长安）主张把皇帝带去洛阳；董白带董卓的旧卫，貂蝉同行，皇甫嵩守门；冲过王允的关卡和追兵，徐晃见了天子倒戈护驾，函谷关打李傕（首领）→ 三月到洛阳，孙坚跪迎。长安陷落，王允死在城门上，吕布投奔河内张杨，李傕、郭汜占据长安。孙坚留着玉玺，自任**大将军 · 录尚书事**（挟天子的成了孙坚——主角心想：课本上写的是曹操啊）；皇帝不情不愿地把孙坚当年的旧号**破虏将军**给了主角。
* **南阳征伐（初平三年夏）**：主角在洛阳被排挤了一年，因为孙坚离不开天子，被派去打南阳的袁术。桥蕤；黄忠（被袁术兵抢光的南阳兵，儿子黄叙病重）入队；雷薄、陈兰；冯夫人夜访；孙坚旧部认得主角手里的虎符，打开宛城东门，里应外合；纪灵（首领）断后，和袁术、冯夫人一起向东逃走。
* **四周目（有「结局三 · 恨海」）**：出逃路上换成李傕的追兵张绣（渭水桥）和张济（渭水营），主角把他们的谋士**贾诩**捆上粮车带走；到洛阳后松绑，好酒好肉、头一碗红烧肉，贾诩一耸肩：「……行吧。」入队。

**故事线（六幕）**

1. **第一幕：双凤乱太行 · 郑好与姜巧**
   * 【初平三年 · 夏】界桥之后，斑马军在太行站稳了脚，可山外围还有两股谁也不服谁的女匪：郑家寨的大当家泼辣悍勇，一口厚背大刀专打强攻；姜家寨的大当家刁蛮机灵，一身暗器机关。两寨仇杀多年，商路被她们搅得没法走。（两人都是二十岁上下的成年女子。）
   * {lord}（内心）：女土匪？没听过。……三国演义我不熟，可这两位肯定不在里面。
   * 主角「以暴制暴」，两寨各打一仗（两场精英战），把两位大当家都擒了回来。两人被绑在一根柱子上还在对骂。主角收她们当贴身近卫，顺手赐名：郑家的叫**郑好**（「正好」），姜家的叫**姜巧**（「将巧」——{lord}：「谐音差点意思，差不多就行。」）。两人异口同声：「凭什么她的名字比我的好听？」
   * **抉择**：【把两人关一屋，调解到和好为止】→ 主角搬了把椅子坐在门口，听两人从吵架吵到对骂、从对骂吵到一起骂他，天亮时两人勾着肩出来了。记「郑姜：和好」；【随她们去】→ 记「郑姜：内讧」（这一步决定第二幕的生死）。

2. **第二幕：吕布北来 · 太行山口**
   * 【初平三年 · 冬】长安陷落后，吕布先投了河内的张杨，又转投袁绍。袁绍正愁太行的黑山军，借刀杀人，派他来剿。吕布不知道山里是谁，也懒得问——黑山的粮和马，够他的并州兵吃一冬。
   * 吕布的并州狼骑先到，高顺的陷阵营一步一步压上山口——**精英：太行山口 · 高顺陷阵营**。{lord}（内心）：高顺？没听过。……这些兵一声不吭，盾墙连成一片，比喊得响的可怕多了。
   * 吕布亲自杀到，赤兔马在山口一停，盯着主角的脸看了半天：「……你？江东那个短毛？头发怎么长出来了？」{lord}一头雾水：「什么江东？我河北的！」（吕布在南线第二章劫营时见过南线主角——这是他第一次「认脸」，此后越来越不对劲。）
   * 他又看见了主角身后的吕玲绮，脸色一下子铁青：「……逃了婚，还钻进土匪窝里当贼？我吕奉先的脸，都让你丢尽了。」画戟一抬，指的不是主角，是她：「吕家没有这样的女儿——今天我亲手清理门户。」吕玲绮握紧小画戟，没有退：「我是吕玲绮。」
   * **首领：太行山口 · 吕布**（复用南线的吕布，基本打不赢）：
     * **「郑姜：内讧」**：两寨的人各守各的山头，谁也不肯补位，防线一冲就散 → **【结局七 · 绝罚】**。
     * **「郑姜：和好」**：打不赢不算失败——危急关头两位姑娘使出了江湖野路子：姜巧朝吕布脸上连砸三大包陈年辣蓼生石灰，又拉起一道抹满马粪的烂泥绊马索；郑好带人推下滚木礌石，漫天泼热黑油、撒铁蒺藜，扯着嗓子大喊「非礼啦——并州兵耍流氓啦！」。飞将吕布被石灰迷了眼、满身恶臭，赤兔马被呛得直打喷嚏。两人拽着主角和吕玲绮钻进了山缝，在山洞里躲了一夜（强制休整）。记「太行：金蝉脱壳」；**打赢了**（极难）：吕布第二次栽在「卖粮的」手里，记「吕布：太行败走」，三只宝箱。

3. **第三幕：夜渡黄河**
   * 【初平四年 · 春】袁绍的大军跟着压上来，冀州已经容不下斑马军。张燕拍着主角的肩：「山还在，你们什么时候回来，路都给你们留着。」——黑山的协定照旧，张燕留守太行。
   * 黄河渡口，袁绍的追兵咬了上来（普通战 · 冀州骑兵）。渡过河，全军不知去向，**张夫人**摊开地图：「去徐州，找东海的糜竺。甄、糜两家几代人做生意，他借得出一块落脚的地。」

4. **第四幕：北海 · 太史慈单骑求救**

5. **第五幕：北海城下 · 管亥**

6. **第六幕：刘备来迟 · 孔融让北海**
   * 【初平四年 · 秋】平原相刘备带着关羽、张飞赶到，围已经解了、管亥降了、太史慈也归了心，扑了个空。{lord}（内心）：刘关张——虎牢关下见过。……这一回，是我先到的。
   * 徐州使者**糜芳**浑身是血地赶来求援：曹操为父报仇，正在血洗徐州。刘备急着立功，当即带关张南下。{lord}（内心）：糜芳？没听过。……不过姓糜，跟张夫人说的那个糜竺，八成是一家。
   * 孔融把主角请进郡府。{lord}（内心）：孔融！这个我知道——孔融让梨！课本上的！孔融捋着胡子，把北海相的印推了过来：「老夫要去洛阳朝廷述职。北海的百姓认你，这印，让给你。」{lord}（内心）：……让梨让到让北海，这位是真的会让。
   * 孔融上表朝廷，力荐主角为北海相。诏书下得出奇地快——**跨线彩蛋**：若存档里有南线的「南阳：袁术东逃」，传诏的宦官盯着主角看了半天：「……将军前些日子不是还在南阳打袁术吗？头发怎么长出来了？」记「北线：北海相」，第五章接徐州。

**故事线（九幕）**

1. **第一幕：整备南下 · 痛击曹军**
   * 【兴平元年 · 夏】曹操为父报仇血洗徐州，糜芳又一次跑来求援。主角在北海整军南下——
     * **有「军纪：严明」**：夏侯兰拔刀插案：「外头当我们是商贾加土匪。带几万人去，人家只会更怕；黑山降兵野性一发作，反成祸患。救徐州，靠精兵和铁律。」主角依计，大队留北海屯田，只带三千精锐轻装南下。
     * **没有**：主角把能带的都带上了，浩浩荡荡几万人。
   * 行到下邳城外，正赶上曹操的老巢兖州被吕布偷袭，曹军急着撤兵。斑马铁骑从侧翼山林杀出，赵云一枪挑飞**夏侯惇**的护心镜，太史慈连珠三箭射翻曹军牙旗——**中段首领：下邳城外 · 夏侯惇殿后军**。{lord}（内心）：夏侯惇……拔矢啖睛那个？电视剧里看过。真人两只眼睛都还在。打完进城，强制休整。

2. **第二幕：陶谦让印 · 刘备「秒接」**
   * 主角和刘关张一起走进刺史府，病榻上的徐州牧**陶谦**面如金纸。{lord}（内心）：陶谦……「三让徐州」那个陶谦！要让了，要让了——
   * 陶谦看着手握北海兵权、身后赵云太史慈威风凛凛的主角，心里发怵；再看汉室宗亲刘备，大喜，当众命人捧出徐州牧印：「愿将徐州托付与玄德公！」
   * 照规矩刘备该推辞三次。可他眼角余光扫着旁边兵强马壮的主角，心里打鼓——*万一这北海来的年轻使君客气一声先应承下来……* 刘备一步跨上前，长跪谢恩，连半句推辞都没有，双手稳稳接过了大印。
   * 张飞摸着后脑勺发懵。{lord}（内心）：大耳贼果然是影帝，说好的三让徐州呢？这手速比抢红包还快！记「刘备：秒接徐州印」。

3. **第三幕：糜府夜宴**
   * 徐州别驾、巨贾**糜竺**在城里最大的酒楼摆了百桌接风宴。{lord}（内心）：糜竺……张夫人一路上念叨的那位。看着像个笑眯眯的财神爷。糜芳拉着赵云的手直夸神枪。
   * 酒过三巡，屏风轻响，糜竺的小妹**糜贞**（二十岁上下）捧着白玉酒壶走出来，大大方方走到赵云案前斟满：「小女子代徐州父老，敬子龙将军。」素来视万军如无物的赵子龙，耳根一下子红透，连饮三爵。{lord}（内心）：子龙，你也有今天。
   * 后堂雅间里，张夫人和糜竺铺开地图谈了一夜，敲定甄、糜两家在东海海运、盐、铁上的全面合作。

4. **第四幕：后堂施针 · 圣女被认出**
   * 陶谦病势突然恶化，主角请**张宁**进内堂施针。九枚金针下去，陶谦咳出一口黑血，缓过来了——这一针，替他多续了一年的命。
   * 帘后站着徐州名士**陈登**。{lord}（内心）：陈登？没听过。……眼神这么尖的人，不会只是个看热闹的。他身边一名心腹校尉早年是巨鹿太平道的亲兵，在烛光下看清了张宁颈间那块刻着「太平」的黄玉佩，浑身汗毛倒竖，退出内堂附在陈登耳边：「公子……榻前施针的女神医，是天公将军的女儿，当年的黄巾圣女张宁！」

5. **第五幕：分岔 · 门后之诛 / 铁面夏侯兰**
   * **没有「军纪：严明」→【结局八 · 门后之诛】**：几万黑山降兵在下邳街头酗酒抢东西、打砸商铺，士绅百姓怨声载道。陈登深信主角是借商贾外皮的乱党，告到陶谦和刘备那里；刘备一锤定音：「黑山贼寇勾结黄巾妖女，借治病之名混进下邳——此等逆贼，万不可留！」陶谦在后堂摆「谢恩宴」，宴到一半金钟乱鸣、房门尽封，刀斧手和连弩齐出（「陶府后堂 · 刀斧手」，打不赢，lose_goto）。主角挺枪把张宁护在身后，背上中了数十支毒弩，倒在血泊里（写得克制，不露骨）。
   * **有「军纪：严明」→ 正线**：
     * 两个老兵顺手摸了百姓一匹布，夏侯兰当众扒了甲胄，八十军棍，革职示众。
     * 徐州大将**曹豹**纵兵抢民女。{lord}（内心）：曹豹？没听过。……不过这副德性，史书上写他好人才怪。夏侯兰单骑拦街：「曹将军纵兵作恶，与董贼何异！」曹豹的家兵拔刀——**精英：下邳街头 · 曹豹家兵**，赵云挺枪压阵，曹豹狼狈而逃，满街百姓叫好。
     * 陈登夜里提着两坛酒来探营。主角不绕弯子：「元龙兄，是你的旧部认出张宁了吧？不错，她是张角的女儿。可她只给人治病；我手下这些人，从前当贼是为了活命——跟着我，就不会再当贼。」
     * 陈登回家告诉老父**陈珪**。{lord}（内心，后来听说）：陈珪？没听过。……能一句话把儿子点透的老头，是真老狐狸。陈珪抚掌大笑：「满口仁义的，多是刘玄德那种急功近利的；敢对你坦白妖女和贼众身世的，才是真豪杰。」陈家父子从此暗中倒向主角。记「陈家：倒向主角」。

6. **第六幕：吕布来了 · 郭嘉的板凳**
   * 【兴平二年 · 夏】吕布在兖州被曹操打得大败，带着并州兵和谋士**陈宫**来徐州借粮。{lord}一听就拍了桌子：「人中吕布、马中赤兔！收拾铺盖卷，回北海！」吕玲绮脸色煞白，手指死死攥着衣角——在太行，她的父亲是真的要杀她。主角把手轻轻覆在她冰凉的手背上。
   * 被晾成「光杆司令」的徐州牧刘备两眼放光：引吕布驻小沛，正好制衡这北海来的小子和徐州本地的门阀。陈登拍案：「吕奉先三姓家奴，先弑丁原，后诛董卓——引狼入室！」
   * 郭嘉晃着酒葫芦出来打圆场：「玄德公说得对，不如亲自出城去迎温侯。」刘备大喜，急匆匆去找关张。主角一把拉住郭嘉：「你喝高了？把那头人形哥斯拉引到小沛？」郭嘉打了个酒嗝：「主公，搬个小板凳，看戏。」
   * 原来郭嘉早在侧堂见过吕布的信使，也见过吕玲绮。他对吕玲绮说：「温侯要是入了徐州，主公和你都没好日子过。这一回，换你替主公撑伞。」吕玲绮咬着牙对信使说：「我在徐州……很想念父亲，让他放心来投。千万别跟刘备说——刘备不是好人。」郭嘉塞给信使一锭金子：「你家温侯天生多疑，你只要把『刘备不是好人』原话带到。」

7. **第七幕：小沛城外 · 吕布暴揍刘玄德**
   * 信使和满面春风出城相迎的刘关张一起到了吕布军前，附耳密报：「温侯，小姐确实在徐州……但刘备不是好人！」吕布一眼看见刘备身后关羽、张飞刀出鞘、弓上弦，虎牢关下三英围他的旧恨一下子翻上来——*那逆女恨透了老子，刘大耳又带着关张埋伏，分明是串通好了要做掉我！*
   * 赤兔马一冲而出，画戟照着刘备面门劈下：「织席贩履的大耳贼！勾结那逆女埋伏某家，当我眼瞎不成？！」刘备抱头鼠窜：「奉先兄！什么逆女？！」关羽张飞拼死断后，护着鞋都跑丢了一只的刘备逃走。
   * 刘备不敢回下邳，小沛又被吕布占了，想起曹操的招揽密信，仰天长叹：「徐州那北海小子和郭奉孝，欺备太甚！今天下英雄，唯曹孟德能容我耳！」带着关张投了兖州。记「刘备：投曹」。

8. **第八幕：陶谦遗表 · 小沛合围**
   * 陶谦心里雪亮这一出是谁的手笔，却冷笑：「老夫试探让印，他连半句推辞都没有——这种人走了干净。」命陈登、糜竺把徐州兵符交给主角，全权迎击吕布。
   * 主角和赵云、太史慈、夏侯兰合围小沛：城外两战（小沛城外 · 并州狼骑、城下 · 陷阵营兵），夏侯兰的哨卡密不透风，小沛渐渐粮尽。
   * 淮南的袁术刻了一方假玉玺（真的还在洛阳孙坚手里），扬言天命在己。走投无路的吕布想投袁术换粮，陈宫死谏：「袁公路冢中枯骨！」两人大吵，城里军心散了。
   * 夜里，吕布丢下陈宫和大军，单骑撕开包围圈——**首领：小沛城门 · 吕布突围**（打赢了他也会跑：赤兔马太快）。冲过吕玲绮身边时，他勒了一下马：「逆女，下回见面，我亲手取你的头。」然后头也不回地奔寿春投袁术去了。{lord}（内心）：……第三回了。这人每次见我，都像见了鬼。
   * 【兴平二年 · 冬】陶谦含笑握着主角的手，写下临终遗表送往洛阳朝廷，力荐主角接任徐州牧，溘然长逝。全城缟素。记「徐州：接任徐州牧」。

9. **第九幕：收张辽高顺 · 供养陈宫 · 赵云大婚**
   * 吕布丢下了整个并州军和家眷。吕玲绮站到阵前喊话：「并州的兄弟们！我爹已经扔下你们走了，何苦再死在这里？」张宁进营给伤兵敷药，夏侯兰开仓放粮。**张辽**和陷阵营的**高顺**扔下了刀——高顺长叹：「大小姐在，并州军魂便在。」{lord}（内心）：张辽！这个我知道，游戏里「辽来辽来」那位……高顺在太行山口跟我打过一回，没想到会是这么个结果。记「张辽高顺：入队」。
   * 只有陈宫誓死不降，破口大骂。{lord}（内心）：陈宫……电视剧里放过曹操的那个。这种老专家，杀了可惜，供起来。主角把下邳最清静的宅子辟成「陈先生别苑」，好酒好菜好书供着。陈宫天天骂街，吃得满面红光——有力气骂，却没借口死。记「陈宫：供起来了」。
   * 糜竺请主角和张夫人做媒，把小妹糜贞许给赵云，随嫁粮草、僮仆、骏马和糜家的船队、盐铁生意。下邳十里红妆：赵云穿着大红锦袍，喝交杯酒手都在抖；甄宓捧着凤冠，吕玲绮倚着门框笑，郑好姜巧带女兵堵回廊讨喜钱；夏侯兰破例卸了铁面，红着眼拍赵云的肩：「子龙，常山一别，今天见你成家，值了。」陈宫闻着酒香晃出来，嘴上骂「奢靡忘战」，手上连干三斗。主角登台：「子龙，战场上你能七进七出，今晚这杯合卺酒，你得踏踏实实给弟妹敬满！」记「赵云：成婚」，第六章接讨伐袁术。

## 三、 宿命轮回：全 Bad End 档案库与破局线索

游戏中每个 Bad End 都是极具震撼力与凄美色彩的情感节点，同时也是二目轮回推进的核心机制。

### 1. 【结局一 · 玉碎】（CG：`end_yusui`）
* **触发章节**：南线 · 第三章《传国玉玺》（一周目必经；没留下董白的周目也只能走这条线）
* **剧情脉络**：
  * 孙坚把玉玺托给吴夫人，去打刘表，死在岘山；袁术的人一路追着玉玺不放，纪灵在最后一道山口拦路，被击败后，亲口把孙坚的死讯告诉吴夫人；
  * 袁术的金顶车驾亲至，要玉玺，还要把「孙文台的夫人」一并带回宛城（冯夫人：「她针线活好，给我缝衣裳」）；
  * 吴夫人理了理鬓发，把传国玉玺举起来砸在路边的青石上（「孙家的人，不受这种辱」），随后自尽（写得克制，不露骨）：「傻孩子，是娘自己要来的。……别哭。」
  * 主角把孙策推给周瑜（「三弟，带虎子走！」），握着孙坚的旧刀冲向袁术，中箭倒下。
* **结语铭文**：
  > *「宁为玉碎，不为瓦全。江东的梦，碎在了南阳。……也许下一周目，会有不同的结局。」*
* **轮回启示**：带着「结局一 · 玉碎」再来一周目，第二章**留下董白**，第三章救下蔡文姬，就能走上「守洛阳 → 长安」的新路线。

### 2. 【结局二 · 同归】（CG：`end_tonggui`）
* **触发章节**：南线 · 第四章《挟天子》（第一次走到这一章，还没有「结局二 · 同归」，没有人报信）

## 四、 第二卷：中原劫火（第六章至第七章·交汇与背刺）

### 第六章：淮南折帝旗（196年 至 197年）

两条线第一次同场。游戏里每个周目只玩一条线，所以这一章做成两个 quest：北线视角和南线视角，同一场仗各看一面。

**讨袁的起因（两条线一致）**：袁术刻了假玉玺在寿春称帝，还到处说孙坚的真玉玺「是从井里偷的」。洛阳的大将军孙坚（挟着天子的那位）拍了桌子，逼小皇帝下了讨逆诏——诏书发给兖州的曹操和北海相（北线主角），两家**奉诏**出兵；荆襄的南线主角收到的不是诏书，是孙坚的一封**家书**。三路各走各的：曹操中路、北海军东路、荆州水师走水路堵淮水，谁也不和谁同行，只在寿春城下会合。

#### 【北线：淮南折帝旗 · 寿春浮桥】
* **时间**：建安元年（196年）冬 至 建安二年（197年）春——每一幕开头标【年号 · 月】
* **舞台**：下邳 → 淮北 → 蕲阳 → 寿春东门 → 淮水浮桥
* **我方核心**：主角、赵云、郭嘉、太史慈、张辽、高顺、吕玲绮、张宁、夏侯兰（若入队）、郑好、姜巧

**故事线（五幕）**

   * 【建安元年 · 冬】袁术拿着那方假玉玺在寿春僭号称帝，建号「仲氏」。洛阳的讨逆诏送到了下邳，传诏的宦官悄悄说：「这是大将军孙文台的意思——袁术骂他的玉玺是偷的。」{lord}（内心）：袁术……袁绍的弟弟？「冢中枯骨」这个词我记得，好像就是说他的。……孙坚？那个江东猛虎？原来是他在洛阳挟天子。

   * 【建安元年 · 冬】袁术拿着那方假玉玺在寿春称帝，还到处说孙坚的玉玺是「从井里偷的」。洛阳的孙坚拍了桌子，逼着小皇帝下了讨逆诏——诏书发给了兖州的曹操和北海相。
   * 襄阳收到的不是诏书，是一封家书，字又大又歪：「嘴甜的：袁公路那厮刻了个假玺称帝，还骂老子的玺是偷的。诏书是给外人看的，给自家人的是这封信。你带水师走水路，先把庐江拿下来——公瑾家里的人还在舒县受那厮的气——再把淮水给我堵上，别让那厮从水上跑了。——文台。」

3. **第三幕：舒县 · 周家**
   * 【建安二年 · 春】荆州水师顺江东下（江面 · 袁军巡船），在庐江登岸。庐江归袁术管，太守是他的亲信**刘勋**。袁术一称帝，开销翻了几倍，刘勋就在庐江挨家挨户地搜刮：舒县的周家是庐江第一大族，粮仓被封、族里的子弟被拉去充军。{lord}（内心）：刘勋？没听过。……当官当成这样，八成是袁术的亲戚或者酒友。

   * 周家族老开仓放粮，拨出族中子弟和几十条船跟着荆州水师走。周瑜的母亲拉着主角的手：「瑜儿信里常提你，说你欠他一碗粥钱。」{lord}：「……他到底记了多少年？」记「周家：解围」。
   * 舒城的另一头是陆家的旧宅，半边墙还是焦的：前庐江太守陆康不肯给袁术粮，被袁术的兵攻破了舒城，陆家死了一半人。门口坐着一个十四五岁的少年，一言不发地看着荆州水师的船。周瑜低声说：「陆家的孩子，叫陆逊。」{lord}（内心）：陆逊？！……火烧连营那个？现在还是个孩子。——主角让人送去一车粮，少年站起来，规规矩矩作了个揖，什么也没说。（只露脸，埋伏笔；他长大后再登场。）
   * 粮还是不够大军北上。周瑜带主角去了庐江的居巢，找当地一个出了名大方的年轻豪强**鲁肃**借粮。鲁肃家有两座大粮仓，各三千斛，他指着其中一座：「这一仓，都拿去。」{lord}（内心）：鲁肃！这个我知道——电视剧里那个老实人。……老实到一出手就是三千斛？鲁肃又看了周瑜一眼：「公瑾，这粮不用还。我跟你们走一趟，看看这个荆州来的人，值不值三千斛。」鲁肃入队。记「鲁肃：指囷相赠」。

4. **第四幕：皖城 · 解救二乔**
   * 皖城传来消息：袁术称帝后下诏选秀，刘勋要把皖县乔公的两个女儿押去寿春「入宫」，车驾已经备好了。

### 第七章：天下劫火（198年 至 205年）

#### 【北线战场】：泰山剿匪 · 奇袭邺城 ＆ 北海龙虎决

1. **泰山剿匪 · 梁父山整饬商道**：
   * **地理与局势**：寿春战役后，主角为保障青徐与中原各州的陆上商运通畅，亲率大军经略泰山周边（梁父山、奉高、莒县关隘）；
   * **交锋与收放**：泰山地势奇险，盘踞着以**臧霸（宣高）**、孙观、吴敦、尹礼为首的泰山匪帮。臧霸倚仗山险设伏，张辽引并州精骑诱敌深入，夏侯兰严布重步兵大阵当头痛击，数战生擒匪众数百；
   * **夏侯兰的铁纪与隐患**：夏侯兰依法不斩俘虏，严惩私掠，分发口粮遣散老弱，并在险要隘口设立巡检哨卡，正式开辟甄糜两家的私盐粮道。臧霸畏惧主角兵威，只得引众退入深山，表面歃血退兵，暗中却对曹操暗许的“徐州刺史”高官厚禄心存贪念，埋下日后反水偷袭的毒种。

2. **河北烽烟 · 易京大决战公孙瓒覆灭**：
   * **地理与战况**：此时河北传来惊天战报：北方霸主袁绍倾起冀、幽、青数十万主力大军，统领颜良、文丑、高览等猛将，在易水之畔与白马将军公孙瓒展开关乎北方霸权的生死大决战；
   * **易京覆灭**：公孙瓒在易京挖掘十重壕沟、筑起五六丈高垒、广积粮草作困兽之斗。谋士审配献“地道穴攻”之计，袁军挖掘地道穿透高垒、烈火焚烧楼基，重楼铁门连环崩塌；公孙瓒穷途末路，拔剑先斩妻妾，随后引火自焚！威震北疆的白马义从彻底覆灭，河北袁绍声威达到顶峰！

3. **决意复仇袁绍 · 滏口密道 ＆ 奇袭邺城（一雪前耻）**：
   * **复仇动机**：主角忆及当年刚降临冀州时，袁绍手下郭图纵兵意图屠戮甄府、迫使主角流亡太行的旧恨，当机立断拍案决策——“趁虚捣穴，复仇袁绍！”
   * **战略空窗期**：袁绍数十万主力远在幽州易京打扫战场，其核心政治与后勤粮饷老巢**邺城**（漳水北岸）兵力极度空虚，仅留谋士郭图、审配之侄审荣守城；
   * **联合黑山各路义军**：主角凭借早年树立的“斑马义旗”与救治神医张宁的天公大恩，秘密联络太行山黑山军总渠帅**张燕（飞燕）**。张宁以太平道信物登坛号召，太行山十余万黑山好汉群起策应；
   * **雷暴奇袭 · 广阳门破**：
     * 高顺陷阵营七百死士为攻坚锋刃，张辽、太史慈、吕玲绮引铁骑精锐借太行雷暴大雨自**滏口陉**秘道神兵天降，昼夜兼程直插邺城城下；
     * 太史慈在百步开外连珠三箭射落城头守将，高顺陷阵营搭云梯破关；
     * 潜伏在城内的**张夫人**暗中联络甄家邺城分号的数百伙计、护卫暴起发难，斩杀守门校尉，轰然大开邺城东门（广阳门）！

### 3. Bad End 脚本编写三原则（黄金法则）
为确保后续新增 Bad End 保持高艺术水准，所有新分支需严格遵循：
1. **崇高与悲壮，杜绝恶趣味**：死亡必须源于角色的主动抉择、守护与牺牲，绝不设计卑劣的侮辱或无意义暴毙。
2. **Meta 破局密码（结语线索）**：每个 Bad End 的结算画面必须附带类似“下一周目，去找一个……”的系统暗号，形成跨周目解密乐趣。
3. **记忆回响**：在达成真结局时，所有曾在 Bad End 中牺牲过的红颜知己，都会在最终章的交互与台词中留下“似曾相识”的既视感彩蛋，让玩家的每一次轮回都拥有厚重的情感沉淀。

  * **吕玲绮**：身披银锁甲，英姿飒爽，彻底走出将门阴影，为天子近卫统领；
  * **甄宓**：当年扒门框喊「账房哥哥」的小丫头，已长成亭亭玉立的洛神仙子，凤冠霞帔嫁给了主角——张夫人一边给她理嫁衣一边哭：「娘把宓儿交给你了。」主角（内心）：当年给她揉丫髻的时候，哪想得到今天；
  * **郑好、姜巧**：御前一等贴身侍卫女官，一个管近卫冲锋，一个管暗哨防谍，依然天天拌嘴争宠；
  * **郭女王**：总领尚书台文书与机要秘策司，女中文德，目光如炬；
  * **马云騄**：统领西凉红缨铁骑，巡狩丝路商道，英武非凡；
  * **赵云、马超、太史慈、张辽、郭嘉**：受封上将与国公，统御北境雄师与神射重兵，名震四海。
* **南线眷属**：
  * **吴夫人**：以太后之尊坐镇后宫，慈柔温婉，依旧把皇帝当孩子管；
  * **董白**：褪去骄纵化作贴心娇嗔，依旧掌管飞熊禁军；
  * **蔡文姬**：修典注乐，长伴君侧抚琴；
  * **貂蝉**：倾城之舞只为一人独舞；
  * **孙尚香**：统领大吴红妆羽林营，任性飒爽，长伴君侧；
  * **祝融夫人**：统领南中十万蛮族与【无当飞军】，野性英姿，伴君巡狩；
  * **吴苋**：入主西宫，料理川蜀江南财赋礼制，温婉典雅；
  * **孙策与大乔、周瑜与小乔、黄忠、甘宁**：统领庞大陆海雄师与远洋舰队，经略万里（二乔随夫远航）。

### 2. 终局爆笑修罗场：
* 国宴之上，张夫人与吴夫人核对两地内库账册，愕然发现记账格式完全一致；
* 蔡文姬与甄宓交流陛下早年“所作”诗词，发现打油诗与现代流行歌词如出一辙；
* 郭女王与辛宪英暗中核对当年南北两线的兵机密档，相视一笑：「原来两位圣上从一开始就在打同一张算盘」；
* 吕玲绮、马云騄、董白、孙尚香与祝融夫人猛然拍案，终于把皇帝堵在内廷屏风后：
  > **吕玲绮 / 马云騄 / 董白 / 孙尚香 / 祝融夫人**：「好啊你个大骗子！当年黄河边、浮桥上、长江边、泸水畔你跟我们说那是‘同乡旧友’……合着你们俩从头到尾就是同一个人？！」
  > **貂蝉 / 甄宓 / 蔡文姬 / 郭女王**（微笑围上）：「陛下……今晚这后宫，您打算怎么翻牌子呀？」
* 年轻的帝王揉着太阳穴，露出那个熟悉的洒脱微笑：
  > *「加了十年班……拯救了整个天下，这辈子，总算能过上神仙日子了！」*
