# Bundled fonts

Subsets built by `python tools/build_fonts.py` (common GB2312 characters + every character in the game data and scripts).

- `body.ttf` — Noto Sans SC (思源黑体), weight 500. © Google / Adobe, SIL Open Font License 1.1.
- `name.ttf` — LXGW WenKai Medium (霞鹜文楷). © LXGW, SIL Open Font License 1.1.

Both may be bundled and redistributed with the game; the licence text is at https://openfontlicense.org.
