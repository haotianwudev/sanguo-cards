# 美术总设计

这份文档是整个游戏美术的**总表**：要画哪几类图、每类的规格和风格、现在缺多少、先画什么。
其他几份文档的分工：

| 文件 | 写什么 |
|---|---|
| `ART-PLAN.md`（本文件） | 分类、规格、现状、优先级（手写，改了玩法就更新） |
| `CARD-DESIGN.md` | 卡面布局、UI 资源规格、§7 每个角色的外形说明（画人之前必看） |
| `ART-PROMPTS.md` | 每张图的完整出图提示词（`python tools/art_prompts.py` 生成，已交付的自动消失） |
| `ART-NEEDS.md` | **按章节的完整清单**：立绘、敌人、卡、战斗背景、剧情 CG、结局卡、幕间、奇遇插图、地图底图，逐条标 ✅ / 🟡 / ⬜（`sanguo-art` 生成） |
| `../docs/STORY.md` | 剧情大纲：画剧情 CG 前看一眼这场戏在讲什么 |

现状数字是 2026-09-30 重新盘点的（Gemini 交完第二章 CG、天命、词缀、标题之后）。盘点方法：扫一遍游戏数据里实际用到的每个 key，对照已交付的图和提示词；**所有用到的图都已经有提示词**。

## 1. 风格总则

- **整体**：日式战术卡牌 RPG 的厚涂赛璐珞（参考兰斯十）+ 中式底子：宣纸、水墨、朱红印章、金线。
  界面默认是暖色的「墨」主题深色底，所以画面整体偏暖、偏暗也不会违和；**主要在手机上看**，轮廓要清楚、剪影要好认。
- **人物**：
  - 外形必须和 `CARD-DESIGN.md` §7 的设定对得上。
  - 主角：短发（汉代少见），孙坚的银色虎纹旧甲，黑色白毛边披风；虎皮只在甲裙内衬，**不是虎皮披风**（虎皮披风是孙坚的）。
- **内容红线**：
  - 女性角色一律画成成年人。
  - 主角第一章 18 岁，之后只会更大。
  - 汉献帝是十岁左右的孩子：只画孩子该有的样子，和任何暧昧画面都不同框。
  - 悲剧场面（玉碎、同归、董卓之死）要克制：不画血腥、不画伤口特写，用构图、光线、象征物来表达。
- **器物、服饰**：汉代样式。不要西式圆盾、奇幻符文、中世纪纹章（`inf_n` 的希腊式盾牌就是反例，要重画）。
- **图上不要有文字**：可读的字只允许出现在旗帜、牌匾这些本来就写字的地方，并且要和剧情一致（「孙」「袁」「董」「李」旗）。

## 6. 交图流程

1. 按 key 命名，放到第 2 节表里写的位置。
2. 立绘、战斗 CG、剧情 CG、地图登记到 `pics/art.json`，然后跑 `sanguo-art`。
   宝物、天命、词缀、宝箱、标题直接放进 `godot/data/art/` 对应的文件夹。
3. 跑 `python tools/art_prompts.py`：已交付的会从提示词列表里自动消失。
4. **不要覆盖已经交付的图**；按路径 `git add`，只提交自己的图。
