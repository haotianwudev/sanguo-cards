# 美术总设计

这份文档是整个游戏美术的**总表**：要画哪几类图、每类的规格和风格、现在缺多少、先画什么。
其他几份文档的分工：

| 文件 | 写什么 |
|---|---|
| `ART-PLAN.md`（本文件） | 风格总则、每类图的规格（手写） |
| `CARD-DESIGN.md` | 卡面布局、UI 资源规格、§7 每个角色的外形说明（画人之前必看） |
| `ART-PROMPTS.md` | 每张图的完整出图提示词（`python tools/art_prompts.py` 生成，已交付的自动消失） |
| `ART-NEEDS.md` | **按章节的完整清单**：立绘、敌人、卡、战斗背景、剧情 CG、结局卡、幕间、奇遇插图、地图底图，逐条标 ✅ / 🟡 / ⬜（`python tools/sanguo_art.py` 生成） |
| `../docs/STORY.md` | 剧情大纲：画剧情 CG 前看一眼这场戏在讲什么 |

## 1. 风格总则

- **整体**：日式战术卡牌 RPG 的厚涂赛璐珞（参考兰斯十）+ 中式底子：宣纸、水墨、朱红印章、金线。
  界面默认是暖色的「墨」主题深色底，所以画面整体偏暖、偏暗也不会违和；**主要在手机上看**，轮廓要清楚、剪影要好认。
- **人物**：
  - 外形必须和 `CARD-DESIGN.md` §7 的设定对得上。
  - 主角：短发（汉代少见），孙坚的古铜鎏金旧甲（云纹护肩、鳞片甲裙），朱红内衬战袍，纯黑披风（无毛边）；形象以 `pics/source/generals/lord_south_armor.jpg` 为准。**虎皮披风是孙坚的，主角不穿。**
- **内容红线**：
  - 女性角色一律画成成年人。
  - 主角第一章 18 岁，之后只会更大。
  - 汉献帝是十岁左右的孩子：只画孩子该有的样子，和任何暧昧画面都不同框。
- **器物、服饰**：汉代样式。不要西式圆盾、奇幻符文、中世纪纹章（`inf_n` 的希腊式盾牌就是反例，要重画）。
- **图上不要有文字**：可读的字只允许出现在旗帜、牌匾这些本来就写字的地方，并且要和剧情一致（「孙」「袁」「董」「李」旗）。

## 2. 分类与规格

| # | 类别 | 规格 | 放哪里 | 游戏里怎么用 |
|---|---|---|---|---|
| A | 人物立绘 | 竖版 3:4 / 5:7，≥1000×1400，带场景背景 | `pics/source/generals/`（兵卡 `soldiers/`），登记 `art.json` 后跑 `python tools/sanguo_art.py` | 卡面、对话头像、敌人头像 |
| B | 战斗 CG | 横版 16:9，1920×1080 | `pics/source/battles/<场景 key>.jpg` | 兰斯式战斗画面：CG 占上半屏，本身就是敌人（受击抖动） |
| C | 剧情 CG | 横版 16:9，1920×1080 | `pics/source/cg/<key>.jpg` | 剧情格、幕间过场全屏插图 |
| D | 奇遇插图 | 同 C，key = `e_<事件 id>` | 同 C | 「？」格随机事件弹出时全屏显示 |
| E | 章节地图底图 | 超宽横幅 3200×1080，三条横向通道留空 | `pics/source/map/bg_<quest>.jpg` | 走格子地图的底图，左右卷动 |
| F | 宝物图标 | 256×256 透明 PNG，纯器物，不加圆盘 | `godot/data/art/relics/<id>.png` | 宝物三选一、部队界面 |
| G | 天命图 | 512×512 透明 PNG，玉金圆徽中间一个象征物 | `godot/data/art/fates/<id>.png` | 开局三选一「天命」（没有图时显示一个汉字） |
| H | 词缀徽记 | 128×128 透明 PNG，朱红印章样式 | `godot/data/art/affixes/<id>.png` | 精英 / 首领格说明里词缀名前的小徽记 |
| I | 结局卡 | 横版 16:9，象征性、不画人 | 同 C，key = `end_<结局>` | 结局名的底图（压暗显示） |
| J | 标题画面 | 横版 16:9，中间三分之一偏暗（放菜单） | `godot/data/art/ui/title.jpg` | 标题画面背景（压暗显示） |
| K | 宝箱 | 512×512 透明 PNG | `godot/data/art/ui/chest_*.png` | 开宝箱动画（✅ 已有） |
| L | 界面件 | 见 `CARD-DESIGN.md` §2 / §5 | `godot/data/art/…` | 卡框、徽记、格子图标、棋子等（大多已有） |

G、H、I、J 这四类的代码已经接好：图放进对应文件夹就会自动显示，没图时保持现在的样子。

## 3. 缺什么、先画什么、怎么交

- **还缺哪些图**：`ART-NEEDS.md`（`python tools/sanguo_art.py` 生成，按章节逐条 ✅ / 🟡 / ⬜）——不在这里手写清单，手写的会过期。
- **先画什么**：`ART-PROMPTS.md` 顶部的「下一批」，从游戏数据算出来（首领图 → 精英图 → 主线 CG → 普通战斗背景 → 宝物 → 奇遇）。
- **提示词**：数据在 `pics/prompts/*.json`，模板在 `tools/art_prompts.py`；出图流程见 sanguo-art-gen skill，交图入库见 sanguo-art-ingest skill。
- **每个角色长什么样**：`CARD-DESIGN.md` §7。
