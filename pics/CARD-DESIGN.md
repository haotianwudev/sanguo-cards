# 卡牌 / 地图设计与美术需求（Godot 横屏版）

目标：像兰斯10的卡一样——**整张立绘为主体，外面一圈有质感的边框，角上是阵营/兵种徽记，底部名牌，数值和技能一眼能读**。
在资源到位之前，游戏里用程序画的占位（色块边框 + 汉字徽记）；资源到了放进 `godot/data/art/`，在 `godot/data/ui.json` 的 `card` 段填路径即可替换，不用改代码。

## 1. 卡面布局（比例 5:7）

```
┌──────────────────────────┐  ← 边框（按稀有度：N 铁灰 / R 青铜蓝 / SR 银紫 / SSR 金）
│(骑)                  SSR │  ← 左上：兵种徽记（圆形）  右上：稀有度宝石
│                          │
│        立  绘            │  ← 立绘满版（约占卡面 70%），人物脸在上 1/3
│                          │
│▓▓▓▓▓ 孙策·中年 ▓▓▓▓▓▓▓▓▓│  ← 名牌（压在立绘底部的半透明横条）：名字 + 版本
│ ⚔ 攻 121      ♥ 兵 490   │  ← 数值：攻击 / 体力（当队长时显示部队加成后的值）
│ [冲锋 AP1] [霸王之怒 AP2]│  ← 技能签：图标 + 名称 + AP 消耗（战斗中就是按钮）
└──────────────────────────┘  ×3  ← 兵卡张数角标
```

战斗中的状态表现：已行动（变暗）、可行动（亮边）、选中（上浮 + 金边）、BOOST（金色光晕）、混乱（紫色图标）。

## 4. 放哪里

原图放进 `pics/source/` 对应文件夹（见 `pics/README.md`）。卡框的用法写在 `godot/data/ui.json` 的 `card` 段：
```json
"card": {
  "frames": {"N": "wood", "R": "bronze", "SR": "silver", "SSR": "ssr", "lord": "gold", "enemy": "iron"},
  "plates": {"wood": [0.30, 0.874, 0.40, 0.076], "...": "..."},   // 名牌位置
  "badges": {"wood": [0.080, 0.078], "...": "..."},                // 兵种徽记位置（角上宝石）
  "name_styles": {"wood": {"color": "#f6e7c8", "outline": "#3a2412"}, "...": "..."}
}
```
没填的项自动用程序画的占位。

现在游戏里用圆形色块 + 一个汉字（虎、玺、釭……）占位。要换成图标：

| 规格 | 说明 |
|---|---|
| PNG 透明，256×256，每件一张 | 文件名用宝物 id（如 `hupi.png`、`qinggang.png`），放 `pics/source/relics/` |
