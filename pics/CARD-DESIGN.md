# 卡牌设计与美术需求（Godot 横屏版）

目标：像兰斯10的卡一样——**整张立绘为主体，外面一圈有质感的边框，角上是阵营/兵种徽记，底部名牌，数值和技能一眼能读**。
在资源到位之前，游戏里用程序画的占位（色块边框 + 汉字徽记）；资源到了放进 `godot/data/art/`，在 `godot/data/ui.json` 的 `card` 段填路径即可替换，不用改代码。

## 1. 卡面布局（比例 5:7）

```
┌──────────────────────────┐  ← 边框（按稀有度：N 铁灰 / R 青铜蓝 / SR 银紫 / SSR 金）
│(骑)                  SSR │  ← 左上：兵种徽记（圆形）  右上：稀有度宝石
│                          │
│        立  绘            │  ← 立绘满版（约占卡面 70%），人物脸在上 1/3
│                          │
│▓▓▓▓▓ 孙策·中年 ▓▓▓▓▓▓▓▓▓│  ← 名牌（压在立绘底部的半透明横条）：名字 + 版本
│ ⚔ 攻 121      ♥ 兵 490   │  ← 数值：攻击 / 体力（当队长时显示部队加成后的值）
│ [冲锋 AP1] [霸王之怒 AP2]│  ← 技能签：图标 + 名称 + AP 消耗（战斗中就是按钮）
└──────────────────────────┘  ×3  ← 兵卡张数角标
```

战斗中的状态表现：已行动（变暗）、可行动（亮边）、选中（上浮 + 金边）、BOOST（金色光晕）、混乱（紫色图标）。

## 2. 需要的美术资源

| # | 资源 | 数量 | 规格 | 说明 |
|---|---|---|---|---|
| 1 | **卡框** | 5 | PNG 透明，1000×1400（5:7），中间镂空，能做九宫格拉伸 | N / R / SR / SSR / 主公 各一；SSR 要有金属光泽 |
| 2 | **名牌条** | 1 | PNG 透明，1000×160 | 压在立绘底部，放名字 |
| 3 | **兵种徽记** | 9 | PNG 透明或 SVG，256×256 | 主公 / 骑 / 枪 / 弓 / 刀 / 谋 / 勤 / 贼（山贼、黄巾）/ 法（法师、方士） |
| 4 | **稀有度宝石** | 4 | PNG 透明，128×128 | N / R / SR / SSR |
| 5 | **数值图标** | 3 | PNG 透明，128×128 | 攻击（刀剑）、体力（旗/心）、AP（铜钱/玉） |
| 6 | **技能类型图标** | 8 | PNG 透明，128×128 | 物理、法术、回复、防御、BOOST、混乱、破防、加 AP |
| 7 | **卡背** | 1 | PNG，1000×1400 | 翻牌动画（宝箱 / 招募三选一）用 |
| 8 | **人物立绘** | 每人 1 | **竖版 5:7，≥ 1000×1400**，PNG 或 JPG | 人物居中、脸在上 1/3、半身到全身；背景简单，或者给一张**透明背景人物层**（最好） |
| 9 | 敌人立绘 | 每个敌人 1 | 同上 | 战斗界面上方用 |
| 10 | 背景 | 3–5 | 1920×1080 | 地图（山野 / 城关）、战斗（山寨 / 关前）、标题画面 |
| 11 | 字体 | 2 | OTF / TTF | 标题用书法/宋体（如 **思源宋体**，OFL 免费可商用），正文用 **思源黑体**；手机和网页没有系统中文字体，必须打包 |

**风格建议**：水墨 + 描金（兰斯10是日式厚涂，我们可以走中式：宣纸底、朱红印章、金线边框），整套卡框、徽记、图标由同一位画师或同一套生成设定出，保证统一。

## 3. 优先级

1. ~~卡框~~（已到位：`pics/card frames`，已抠成透明接入游戏）+ 兵种徽记 9 个
2. 字体 2 套 → 手机 / 网页版必需
3. 数值图标 + 技能图标
4. 主要人物立绘（按 `ART-NEEDS.md`）
5. 背景、卡背

## 4. 放哪里

放进 `godot/data/art/`，在 `godot/data/ui.json` 的 `card` 段写路径，例如：
```json
"card": {
  "frames": {"N": "art/frame_n.png", "R": "art/frame_r.png", "SR": "art/frame_sr.png", "SSR": "art/frame_ssr.png", "lord": "art/frame_lord.png"},
  "troop_icons": {"cavalry": "art/troop_cavalry.png", "...": "..."}
}
```
没填的项自动用程序画的占位。
